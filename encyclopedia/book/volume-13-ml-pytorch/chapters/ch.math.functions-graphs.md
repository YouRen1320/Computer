# 函数、坐标、图像、斜率、指数、对数与求和

上一章把一个具体问题写成代数式；本章进一步研究“输入变化时，输出怎样变化”。函数是这种关系的精确表达，表格列出离散样例，图像让整体形状可见，斜率描述变化速率，指数描述按比例累积，对数反向求次数，求和把多个贡献合成总量。这些概念会在机器学习的特征、损失、训练曲线与指标中反复出现。

本章不教授矩阵、概率或导数。图像是关系的表示，不是装饰；趋势是证据线索，不自动证明因果。每次看图都要回到定义域、坐标尺度、单位和原始数值。

## 1. 什么是函数

函数把允许输入集合中的每个输入，确定地对应到唯一输出。记作 `y=f(x)`，读作“y 等于 f 在 x 处的值”。这里 f 是关系名字，不是与 x 相乘。输入 x 属于定义域，实际得到的输出集合称值域。

“同一输入只有一个输出”不意味着不同输入不能得到同一输出。例如`f(x)=x²`中 f(2)=4，f(-2)=4。也不意味着实现不能依赖配置；只是要把影响结果的所有条件视为输入。一个读取当前时间和随机数却只标注 order_id 的函数，从数学与测试角度并不真正由 order_id 唯一决定。

### 1.1 函数记号与调用

若 `f(x)=2x+3`，则 f(4)=11，f(a)=2a+3，f(x+1)=2(x+1)+3=2x+5。`f(x+1)`不是`f(x)+1`。代入时用括号保留整个输入，这是常见错误点。

程序函数与数学函数相似但不完全相同。程序函数可能修改数据库、抛异常或返回随时间变化的值。纯函数最接近数学函数：相同显式输入得到相同输出且无外部副作用。后续机器学习中的模型推理在固定参数和运行条件下可被看作复杂函数。

## 2. 定义域和值域

定义域回答“哪些输入有意义”。`1/x`排除 x=0；`log(x)`要求 x>0；设备数量通常是非负整数；维修工时可能是非负实数。公式能对某些值运算，不表示业务允许这些值。例如折扣公式能接受 d=2，但 200%折扣通常违反合同。

值域受公式和定义域共同限制。若 `f(x)=x²`且 x 为所有实数，输出不小于零。若 x 只允许 0 到 10，值域是 0 到 100。数据校验、图像范围和测试边界都应来自定义域，而不是随意挑几组数字。

### 2.1 离散与连续定义域

工单数量、重试次数是离散的；时间、温度常近似连续。离散输入图像应画点，不应默认点之间的所有值都有含义。把“设备数 2.5 台”的平滑曲线解释为真实配置可能误导。连续测量在程序里仍由有限精度表示，也不等于拥有无限精确信息。

## 3. 四种表示必须互相一致

同一函数可用自然语言、公式、值表、图像表示。以设备线性折旧为例：初始价值 10000 元，每年减少 1200 元，最低不低于 0。自然语言说明规则；公式可写`V(t)=max(10000-1200t,0)`且 t>=0；值表列 t=0,1,2；图像显示先直线下降后贴近零轴。

四种表示不是重复工作，而是交叉 oracle。公式在 t=1 得 8800，表格和图像关键点也必须一致。如果图像起点是 10000、表格起点是 8800，说明采样索引或“年初/年末”口径不一致。

### 3.1 值表

值表至少列输入、输出和单位。选点要包含端点、转折点、普通点和非法边界附近。规则在 2 小时改变，就应列 0、1、2、2.01、3，而不是只列 5、10。表格还能为自动测试提供精确 oracle。

### 3.2 图像

二维坐标中横轴通常是自变量，纵轴是函数值。点 `(x,y)`表示 y=f(x)。画图前写轴名、单位、最小/最大值、刻度是否均匀、是否从零开始。没有这些信息，曲线形状可以被任意放大。

## 4. 坐标与图像读取

原点是(0,0)，横轴右正左负，纵轴上正下负。读取点先确定两个轴刻度，再投影，而不是凭视觉猜值。多条曲线要有图例；颜色不能作为唯一编码，兼顾无障碍。

### 4.1 截距

y 截距是 x=0 时的值，常表示初始量；x 截距是 y=0 时的输入，常表示耗尽时点。`y=10000-1200t`的 y 截距 10000，x 截距约 8.33 年。但如果定义域只允许整年，实际首次非正的离散时点要另行解释。

### 4.2 图像不是原始数据

抗锯齿、采样、插值和像素都可能隐藏细节。严肃判断要回到数值表或查询。截图缺少交互提示、时间范围与过滤条件，不能单独作为完整证据。保存生成图的输入、代码、轴配置和数据摘要。

## 5. 线性函数与斜率

线性/仿射关系常写 `y=mx+b`。m 是斜率，b 是 y 截距。给两点(x1,y1)、(x2,y2)，x2≠x1，斜率 `m=(y2-y1)/(x2-x1)=Δy/Δx`。斜率单位是“输出单位/输入单位”。价值对时间的斜率可能是 -1200 元/年。

正斜率表示随 x 增大 y 增大，负斜率表示下降，零斜率表示恒定。斜率绝对值描述变化快慢。若横轴时间单位从天改小时，斜率数值改变但关系未变，因此不能只报一个无单位斜率。

### 5.1 平均变化率

两点斜率是区间平均变化率。对于弯曲关系，不同区间斜率不同。平均维修量从第 1 小时 20 增至第 3 小时 50，平均变化率 15 单/小时，但不说明每一分钟都稳定增加 15。

### 5.2 从点和斜率恢复公式

知道斜率 m 和一点(x1,y1)，可用 `y-y1=m(x-x1)`。展开得到截距。恢复后代入原点验证。程序拟合出一条线时也要检查残差，而不是只看参数。

## 6. 分段函数

业务规则经常按区间变化。夜间维修前 2 小时每小时 100 元，之后超出部分每小时 130 元：

```text
L(h)=100h                         0<=h<=2
L(h)=200+130(h-2)                 h>2
```

分段定义必须说明每个边界由哪一段包含，避免 h=2 重复或遗漏。把 h=2 代入两段都得 200，函数在连接处连续；若第二段写成 130h，会跳到 260，可能是规则错误。

### 6.1 开区间和闭区间

`x<2`不包含 2，`x<=2`包含 2。图像常用空心点表示不包含、实心点表示包含。程序条件顺序也影响边界：先写`if h<=2`再`else`比两个互不审查的`if`更安全。

### 6.2 不连续不一定是 bug

起步价、阶梯运费可能在阈值发生跳跃。数学不连续可以是业务合同，但必须明确。测试应验证阈值两侧，监控图也不要用平滑曲线掩盖跳变。

## 7. 函数复合与反函数

复合函数把一个函数输出作为另一个输入，记作`(g∘f)(x)=g(f(x))`。例如分钟转小时 f，再按小时算费用 g。顺序通常不能交换：先折扣后税和先税后折扣在同一比例税基下可能相同，但有固定费用或不同基数时不相同。

反函数撤销原函数：若 y=f(x)，则 x=f⁻¹(y)。存在单值反函数通常要求在所选定义域内一一对应。`x²`在所有实数上没有普通单值反函数，因为 2 与 -2 都映射到 4；限制 x>=0 后反函数为平方根。

验证反函数可做两次回代：`f⁻¹(f(x))=x`与`f(f⁻¹(y))=y`，并检查定义域。单位换算、从总价反求工时都是反函数思想。

## 8. 指数与幂

`a^n`表示 a 连乘 n 次，a 是底数，n 是指数。`a^0=1`（a≠0），`a^-n=1/a^n`，`a^(m+n)=a^m a^n`。不要把`(a+b)^2`误写成`a²+b²`，正确展开含`2ab`。

### 8.1 指数增长

每期按相同比例 r 增长，初值 P，n 期后`P(1+r)^n`。这里每期增长都作用于新的总量，所以是乘法累积。100 每期增长 10%，两期为 121，不是 120。若每期固定增加 10，则是线性 `100+10n`。

复利、用户增长、数据量膨胀都可能近似指数，但长期外推必须谨慎：资源上限、市场饱和和策略变化会破坏固定增长率。短期拟合指数不等于永远指数。

### 8.2 指数衰减

每期保留比例 q（0<q<1），`Pq^n`。设备账面按固定比例折旧、缓存命中影响随时间衰减可用这种形式。半衰期 h 表示每 h 个时间单位减半，可写`P(1/2)^(t/h)`。

### 8.3 指数的数量级

2^10约 10^3，2^20约 10^6。指数很快溢出或变得极小。程序需要检查数值范围，图像可能使用对数轴。不能因为曲线在普通轴上贴近零，就认定值完全相同。

## 9. 对数：指数的反向问题

`log_b(x)=y`等价于`b^y=x`，要求 b>0、b≠1、x>0。对数回答“底数要乘多少次才得到 x”。`log_10(1000)=3`，`log_2(8)=3`。

对数规则：`log(ab)=log a+log b`，`log(a/b)=log a-log b`，`log(a^k)=k log a`。`log(a+b)`不能拆成`log a+log b`。规则都受正定义域约束。

### 9.1 求增长次数

`P(1+r)^n=T`，两边取对数得到`n=log(T/P)/log(1+r)`，要求 P、T>0且 r>-1、r≠0时按情形解释。算出 n 后代回指数式验证。若周期只能取整数，还要根据“至少达到”或“恰好达到”决定向上取整。

### 9.2 常用底数

自然对数以 e 为底，常记 ln；常用对数底 10；计算机信息量常见底 2。不同底数只差常数比例，但数值不同。库函数 `log`默认底数因语言而异，应查文档并显式测试。

## 10. 对数尺度图

普通线性轴上相同距离表示相同差值；对数轴上相同距离表示相同比例。1、10、100可能等距。对数轴适合跨多个数量级，但零和负值无法直接放在普通对数轴上。

线性轴中看似“后期爆炸”的指数曲线，在纵轴取对数后可能接近直线。反过来，对数轴会压缩巨大绝对差异。报告必须标出轴尺度；把对数轴截图当线性轴解读会严重误导。

### 10.1 截断坐标轴

纵轴不从零开始能突出小变化，也会放大视觉差异。成功率 98%到99%在 97.5%起点图上看起来巨大。是否从零开始取决于任务，但必须展示刻度与原始差值，避免操纵感知。

## 11. 求和符号

求和记号`Σ`把一系列项相加。`Σ_{i=1}^{n} x_i`表示从 i=1 到 n，包括上下界，共 n 项。程序语言的半开区间常不包含终点，这是最常见偏一错误。

例：工单时长[10,20,30]的总和是 60，可写`Σ_{i=1}^{3}x_i`。平均值再除项数 3。空集合求和通常定义为 0，但平均值因除以 0 未定义。

### 11.1 求和规则

`Σ(x_i+y_i)=Σx_i+Σy_i`；常数 c 可提出：`Σcx_i=cΣx_i`。`Σc`若有 n 项等于 nc。把求和拆分可优化推导，也可用于交叉验证。

### 11.2 常见封闭公式

从 1 到 n 的整数和是`n(n+1)/2`。可以用循环结果与公式交叉检查小 n。封闭公式快，但只有在上下界和项定义正确时才成立。0 到 n 的和数值与 1 到 n 相同，但项数不同；涉及平均时差异会暴露。

### 11.3 加权和

`Σw_i x_i`是加权和。若权重和为 1，可解释为加权平均；若未归一化就直接叫平均会错。机器学习线性层、损失汇总和指标聚合都会用到。权重还可能为负，此时结果不一定落在样本最小最大之间。

## 12. 从求和到批量指标

总维修时长是时长求和；平均时长是总和除有效样本数；总金额是每单金额求和。不同状态、时区、去重规则会改变集合，从而改变求和结果。公式正确但样本集合错，指标仍错。

写求和时同时写索引集合：`Σ_{i∈closed_orders}`比只写`Σx_i`更清楚。数据库 SQL 的 WHERE 决定集合，SUM 决定聚合；Python 分析也应保存过滤条件。业务状态事实来自 Java/API 或权威数据库快照，Python不应重新解释状态。

## 13. 图像的系统阅读协议

按以下顺序读图：

1. 标题实际声称什么；
2. 横纵轴变量、单位、范围；
3. 线性还是对数尺度，是否截断；
4. 数据时间窗、时区、采样和过滤；
5. 点、线、面积各表示什么；
6. 是否有缺失、插值、平滑；
7. 关键点、斜率、转折和异常；
8. 回到原始数值验证；
9. 区分相关、预测与因果；
10. 记录仍未验证的解释。

### 13.1 平滑线的风险

移动平均能减噪，也会延迟峰值并掩盖短故障。只有平滑线而无原始点，无法判断异常是否被抹去。保存窗口大小、居中/向后窗口和边界处理。

### 13.2 双纵轴

双轴图可以通过选择尺度制造任意相关外观。优先拆成共享横轴的两个图，或标准化后明确说明。视觉同步不证明一个变量导致另一个。

## 14. 系统化排错

### 14.1 定义域遗漏

对工时 h 使用`log(h)`却允许 h=0，会产生错误或非有限值。首个可信证据是进入函数前的输入与定义域检查，而不是图表渲染报错。修复后测试 0、最小正值、普通值和负值。

### 14.2 坐标尺度误读

监控图纵轴是对数尺度，读者却把等距离当等差。修复不是改数据，而是明确轴标签、提供原始值表并解释倍数。若展示对象不熟悉对数轴，提供线性小图或注释。

### 14.3 指数与对数底数错

用自然对数求 n 时分子分母都用同一底数，结果不变；只对一边用不同底数则错。回代`(1+r)^n`能发现问题。库函数默认底数需要测试。

### 14.4 求和偏一

数学上 i=1…n包含 n，Python `range(1,n)`不包含 n。用 n=1、2、3 的手算样例比大数据更能定位。修复后保留原红用例，并检查空集合契约。

## 15. FactoryCare 综合案例

设备价值函数：`V(t)=max(120000×0.8^t,20000)`，t 为非负整年。值表 t=0 得120000，t=1得96000，t=2得76800。它是指数衰减并有残值下限，不是固定金额线性折旧。

问何时未经下限截断的价值首次不高于30000：解`120000×0.8^t<=30000`，即`0.8^t<=0.25`。对数求临界 t，随后按“首次整年”向上取整并代回 t-1/t 验证。不能只展示小数年份。

维修费函数沿用前2小时100元、超出130元的分段规则。将 h=0、2、3 放入表格，图像在 h=2 处斜率从100变130，但函数值连接。若图像出现跳跃，检查第二段固定部分。

月度工单总成本`Σ_{i∈closed} cost_i`。集合必须由权威 CLOSED 状态和去重规则确定。Python生成图表是派生视图；Java仍拥有工单状态和成交金额。若两端求和不一致，应追查数据版本、过滤和单位，而不是让分析结果覆盖事实。

## 16. 可复核证据包

一次函数与图像实验应保存：函数定义和定义域；输入值表；公式或源代码；轴配置；关键点和斜率手算；指数/对数回代；求和小样本；运行命令和版本；成功、边界、预期失败输出；未验证的业务假设。

图像文件本身不够。别人要能从同一输入重新生成相同关键坐标，并能在不看图时用表格验证。若数据含隐私，保存脱敏样本和摘要，不把生产数据复制进教材仓库。

## 17. 从数据到图像的工程工作流

实际工作往往不是先有公式，而是先有一组时间戳和测量值。仍然可以用函数语言整理：把采样时间视为输入，把当时测量视为输出。但这只定义了观测点之间的映射，不自动定义两点之间发生了什么。折线连接是一种可视化选择，不是证明系统在中间做线性变化。

第一步冻结数据口径。记录查询时间、时区、过滤状态、去重键、缺失处理和聚合粒度。第二步生成机器可读值表，保留原始值与单位。第三步选图形：连续时间趋势可用折线，离散类别比较常用条形，关系散点不要强行连线。第四步设轴和尺度并标关键点。第五步用已知样例检查图上的坐标，最后才讨论趋势。

如果 SQL 按自然日聚合而图表按 UTC 显示，午夜附近工单会落入另一日；如果后端返回毫秒而前端按秒解释，时间轴会跨到荒谬年份。此时“曲线不好看”只是末端症状，首个可信证据是原始值与单位契约。

### 17.1 采样频率与混叠

每小时采样无法可靠展示分钟级尖峰。若服务在每小时第 10 分钟故障 5 分钟，而采样恰好在整点，图可能始终绿色。增加采样、保存事件日志或使用窗口内最大值能提供不同证据。采样不足造成的失真称混叠的一类表现；不能用没有看到尖峰证明尖峰不存在。

反过来，高频数据直接画数百万点会浪费资源并遮蔽结构。下采样时要说明使用平均、最大、最小还是分位数。监控延迟只画平均值会隐藏少数严重慢请求；同时展示 p50/p95/p99 或最大值更合适。概率分位数的正式定义在统计章节学习，本节只建立“聚合选择会改变图像”的意识。

### 17.2 缺失值不是零

时间序列中没有采样，可能表示设备离线、请求未到、采集器故障或真正为零。将缺失补零会制造突然下降；向前填充会假装旧值持续有效；线性插值会制造未观测值。每种策略都有假设，应在图例和数据处理中记录。生产决策中最好同时展示缺失率或采集健康状态。

### 17.3 平移和缩放

若`g(x)=f(x)+c`，图像整体竖直平移 c；`g(x)=f(x-c)`向右平移 c；`g(x)=af(x)`纵向缩放；`g(x)=f(bx)`改变横向尺度。括号内平移方向最容易凭直觉写反，可以用一个已知关键点代入验证。

标准化数据常把 x 变成`(x-中心)/尺度`。这会改变坐标数值但保留可逆关系（尺度非零）。模型输入使用标准化值时，监控和解释必须能映射回业务单位，否则“特征=1.7”对维修人员没有意义。

### 17.4 单调、极值与饱和

函数在区间内随输入增加而不减，称单调不减；随输入增加而不增，称单调不增。设备剩余价值通常应随年数不增，累计工单数应随时间不减。如果数据违反这种结构，可能是更正、重置、口径变化或 bug，不能直接删点。

`max(...,20000)`让折旧函数达到残值后饱和；继续增加年份，输出保持 20000。饱和曲线尾部斜率为零，不代表输入停止变化。机器学习激活、容量上限和评分封顶都可能有饱和，阅读图时要区分“系统没有输入”与“函数输出被限制”。

### 17.5 线性插值与外推

已知两点，在两点之间按直线估值叫线性插值；超出观测范围继续直线叫外推。插值仍依赖中间近似线性的假设，外推风险更高。用前两个月增长率预测未来三年往往不可信。报告应把观测区间和预测区间视觉区分，并列出假设。

## 18. 指数、对数和求和的综合推导

假设每天新增工单按 2%增长，第一天 100 单。第 n 天数量可写`a_n=100×1.02^(n-1)`，因为 n=1 时指数应为0。若写成`1.02^n`，第一天就被增长一次，这是索引偏一。前 N 天总量是`Σ_{n=1}^{N}a_n`，不是最后一天数量乘 N，因为每天不同。

想求哪一天单日数量至少 150：解`100×1.02^(n-1)>=150`，得到`n>=1+log(1.5)/log(1.02)`，再向上取整。验证时把候选 n 和 n-1 都代回，确认“首次达到”。这同时检查对数底数、索引起点和整数取整。

若增长率来自历史拟合，它不是 Java 业务事实，只是可重建分析参数。预测输出应携带模型/数据版本和不确定性；不能把预测工单数写回真实工单计数。数学表达清楚了关系，但“每天固定2%”仍是需要数据验证的假设。

### 18.1 几何级数的直观

`1+r+r²+...+r^(N-1)`是有限几何级数。r≠1 时和为`(1-r^N)/(1-r)`；r=1 时是 N。使用公式前先用 N=1、2 手算，检查首项与项数。很多错误来自把 N 项写成最高指数 N，实际从0开始的 N 项最高指数是 N-1。

公式与循环应互相验证。循环透明但可能偏一；公式快速但可能抄错。对小 N 比较两者，再用较大 N 做性能验证。若浮点 r 接近1，直接公式可能有数值消减问题，数值算法章节会进一步处理。

### 18.2 对数变换的解释边界

对正数取对数能压缩长尾，让倍数关系变成加法。例如金额从100到200与1000到2000，在对数差上相同，因为都翻倍。但回到原尺度，绝对差分别100与1000。模型在对数空间优化的误差，业务解释时必须逆变换。

如果数据包含零，有人会使用`log(1+x)`；它不是普通 log(x)，逆变换也变成`exp(y)-1`。选择这种变换应记录理由。负数需要其他策略，不能随意取绝对值，因为符号可能承载业务含义。

## 19. 诊断报告模板

当表、图、公式不一致时，可按以下格式交接：

- 期望关系：公式、定义域、单位；
- 观测输入：值表和来源摘要；
- 观测输出：具体错误坐标，不只贴图；
- 失败阶段：查询、变换、采样、聚合、渲染或解释；
- 首个可信位置：首次数值发生偏差的代码/步骤；
- 根因：如上界未包含、对数底数误用、轴设为对数；
- 修复：最小关系变更；
- 复验：原红样例、边界、全量和逆向检查；
- 残余风险：外推假设、缺失数据或真实平台未验证。

例如`Σ_{i=1}^{4}i`期望10，程序得到6。日志显示循环输入 n=4 正确，输出6；检查迭代值只有1、2、3，首个可信位置是半开区间构造。修复为包含5的终点后，重跑 n=1、4、100，并用`n(n+1)/2`交叉检查。这样的报告比“range写错了，已修”更可复核。

## 21. 自测与参考答案

1. **函数最关键的映射要求？** 定义域内每个输入对应唯一输出。
2. **`f(x)=2x+3`，f(4)？** 11。
3. **两点斜率单位？** 输出单位/输入单位。
4. **不同输入能有相同输出吗？** 可以，如平方函数的2和-2。
5. **指数增长与线性增长区别？** 前者每期按当前量的比例变化，后者每期加固定量。
6. **`log_b(x)=y`等价于？** `b^y=x`。
7. **对数输入能为0吗？** 普通实对数不能，要求x>0。
8. **Σ上界包含吗？** 标准记号包含；程序区间需另查语义。
9. **对数轴等距离表示什么？** 相同倍数而非相同差值。
10. **越界反例？** 用导数求瞬时变化率，属于后续梯度章节。
