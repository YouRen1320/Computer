# 概率、统计、分布、期望与方差

维修时长不会每次完全一样，告警是否发生带有不确定性，从抽样工单算出的平均数也不等于总体真值。概率论给不确定事件建立规则，统计学用有限观察描述数据并推断总体。两者相连但职责不同：概率常从假定机制推结果，统计常从观察结果反推机制或总体特征。

本章从样本空间、事件、条件概率讲到随机变量与常见分布，再学习均值、中位数、分位数、方差、标准差、期望和抽样偏差。所有计算先用小样本手算，再由 NumPy 复核。我们不会用相关系数冒充因果结论，也不会把固定种子的玩具模拟包装成真实生产数据或模型效果。

## 1. 不确定性不是“完全不知道”

一枚理想硬币下一次正反面不确定，但可以给每种结果概率。设备明天是否告警也不确定，不过它受设备状态、使用环境、观测缺失和偶然扰动共同影响。概率是对这种不确定性的量化，不是“事情一定按比例发生”的承诺。

概率在 0 到 1 之间。0 表示在模型中不可能，1 表示在模型中必然。概率 0.3 不表示每十次必定恰好三次；它表示在明确条件和重复机制下，长期频率可能接近 0.3。有限样本会波动。

### 1.1 模型概率与经验频率

模型概率来自规则或假设，例如理想骰子每面 `1/6`。经验频率来自观察，例如 60 次出现 12 次，频率 `12/60=0.2`。频率是随机样本的结果，概率是模型参数或目标量。样本越多，频率通常更稳定，但数据偏差不会仅靠数量自动消失。

### 1.2 先写观察单位

“告警概率”缺少观察单位：每台设备每天至少一次？每个传感器每分钟？每张工单生命周期内？不同单位产生不同样本空间。任何概率前先写对象、时间窗、过滤条件和去重规则。

## 2. 随机试验、样本空间与事件

随机试验是结果事先不完全确定、但可能结果可描述的过程。一次工单可观察“是否超时”，一次设备日可观察“告警次数”。样本空间记作 Ω，包含所有可能基本结果。

若试验是抛一枚硬币，`Ω={正,反}`。若观察一天告警次数，可能写 `Ω={0,1,2,...}`。事件是样本空间的子集。事件 A“至少一次告警”包含 `{1,2,...}`；其补事件 `Aᶜ` 是“零次告警”。

### 2.1 并、交、补

- `A∪B`：A 或 B 至少一个发生。
- `A∩B`：A 和 B 同时发生。
- `Aᶜ`：A 不发生。

“或”在概率中通常是包含式或，允许两者同时发生。若 A 与 B 互斥，交集为空。工单“紧急”和“超时”显然可以同时发生，所以不能当互斥事件。

### 2.2 概率基本规则

`P(Ω)=1`，`P(A)>=0`，互斥事件概率可相加。一般加法公式为：

```text
P(A∪B)=P(A)+P(B)-P(A∩B)
```

减掉交集是为避免重复计算。补事件概率 `P(Aᶜ)=1-P(A)`。检查离散分布时，各互斥完整结果的概率必须和为 1；这是强而简单的 oracle。

## 3. 条件概率

条件概率研究“已知 B 发生时，A 的概率”，记作：

```text
P(A|B)=P(A∩B)/P(B)，要求 P(B)>0
```

分母是条件 B，不是总体大小，也不是目标事件 A。条件相当于把样本空间缩小到 B 发生的那些观察，再问其中多少也满足 A。

### 3.1 手算表格

六张工单中，A 表示“夜班”：前四张为夜班；B 表示“超时”：第一和第五张超时。交集只有第一张：

```text
夜班 A 数量 = 4
超时 B 数量 = 2
同时 A∩B = 1
P(B|A)=1/4=0.25
P(A|B)=1/2=0.5
```

两者方向不同。把 `P(超时|夜班)` 写成 `P(夜班|超时)` 是常见错误，尤其当变量名只有 `a` 和 `b` 时。函数名和参数应直接表达 event 与 condition。

### 3.2 零分母

若观察中没有任何 B，经验条件比例分母为 0，不能返回 0 冒充“概率为零”。真正含义是当前数据无法定义或估计该条件概率。程序应抛出明确错误或返回有类型的缺失状态，由上层决定如何展示。

### 3.3 独立

若 `P(A|B)=P(A)`（在定义成立时），称 A 与 B 独立；等价关系常写 `P(A∩B)=P(A)P(B)`。独立不是互斥。两个有正概率的互斥事件不独立：知道 B 发生就确定 A 不发生。

数据中看起来接近独立，不等于机制上已经证明独立。有限样本误差、分层混合和测量偏差都可能遮蔽依赖。

### 3.4 全概率与贝叶斯公式

若 B1、B2……构成互斥且完整的分组，`P(A)=Σ P(A|Bi)P(Bi)`。贝叶斯公式把条件方向反转：

```text
P(B|A)=P(A|B)P(B)/P(A)
```

它提醒我们：即使某告警在故障设备中很常见，故障本身若非常少见，看到告警后故障概率也未必很高。基础率不可忽略。实际使用还要确认各概率口径来自同一总体和时间窗。

## 4. 随机变量

随机变量不是“随便变化的变量”，而是把样本结果映射为数值的函数。抛硬币可定义 X：正面为 1，反面为 0。工单可定义 T 为维修分钟数，N 为一天告警次数。

随机变量允许用数值工具描述不确定结果。离散随机变量取有限或可数值，连续随机变量在区间取值。真实测量即使记录到有限小数，也常用连续模型近似；选择模型是近似，不是宣称世界真的无限精确。

### 4.1 概率质量、密度与累积分布

离散变量用概率质量函数 `p(x)=P(X=x)`，所有可能值概率和为 1。连续变量用概率密度函数，单点概率通常为 0，区间概率是密度在区间上的面积；密度值本身可以大于 1，只要总面积为 1。

累积分布函数 `F(t)=P(X<=t)`，离散和连续都适用。它从 0 不减地走向 1。经验累积分布函数用样本中不大于 t 的比例估计 F(t)，每个样本点形成一个台阶。

## 5. 常见分布及适用边界

### 5.1 伯努利分布

一次结果只有成功 1 和失败 0，`P(X=1)=p`、`P(X=0)=1-p`。例如“这张工单是否超时”。成功只是数学标签，不一定是好事。期望为 p，方差为 `p(1-p)`。

### 5.2 二项分布

n 次相互独立、成功概率相同的伯努利试验中，成功次数服从二项模型。前提很强：固定 n、两类结果、每次 p 相同、相互独立。连续几天设备告警可能因状态持续而相关，不应自动套二项分布。

### 5.3 分类分布

一次结果来自 K 个互斥类别，各概率非负且和为 1。例如工单优先级可建模为低、中、高三个类别。类别编码 0、1、2 不自动意味着间隔相等；若只是标签，不应把平均编码当真实平均优先级。

### 5.4 均匀分布

离散均匀表示有限结果等可能，连续均匀表示区间内密度恒定。随机抽样函数是否包含右端点、整数上下界规则属于 API 版本表面，需要查文档。现实维修时长很少天然均匀；均匀模型多作为简化基线或随机化工具。

### 5.5 正态分布

正态分布由均值与标准差决定，曲线对称。很多聚合误差在条件合适时近似正态，但“数据有均值方差”不等于正态。维修时长常右偏且不能为负，直接正态可能给负时长概率。应看经验分布、分位数与领域约束。

### 5.6 泊松分布

泊松分布常用于固定区间内事件计数，参数 λ 同时是期望和方差。它假设事件率稳定并具有特定独立结构。告警会成簇、设备间异质时，方差可能远大于均值，简单泊松模型就不合适。

分布名是模型假设的压缩表达，不是看到柱状图相似就获得的事实。选择后要记录观察单位、参数、拟合证据和违反假设的风险。

## 6. 描述统计：先看样本本身

描述统计把一组数压缩成可读摘要。任何单个摘要都会丢信息，因此要组合位置、离散程度、样本量和分布图。

### 6.1 均值

n 个值均值：

```text
x̄=(x1+x2+...+xn)/n
```

维修时长 `[10,20,30,40,50]` 总和 150，均值 30。均值使用每个数，对极端值敏感。若增加 500，均值会大幅上升。必须同时报告样本量和异常值规则。

### 6.2 中位数

排序后位于中间的位置。奇数个取中间值；偶数个常取中间两数均值。它对少数极端值更稳健，但仍不说明尾部分布。上例中位数 30。

均值与中位数谁“更好”取决于问题。总工作量与均值相关，典型体验可能更适合中位数。不能因为中位数好看就隐藏长尾，也不能因为均值易算就忽略偏态。

### 6.3 分位数

q 分位数把排序数据按累计比例分割。中位数是 0.5 分位数。25%分位数 Q1 和 75%分位数 Q3 描述中间一半范围，四分位距 `IQR=Q3-Q1`。

有限样本的分位数位置可能落在两个观察之间，需要插值。不同软件或参数可使用不同定义，因此分位数函数的 `method` 属于版本/配置表面。上例 `[10,20,30,40,50]` 在 NumPy 默认线性方法下 Q1=20、Q3=40，刻意选择这个样本便于手算；项目证据应记录方法，不能只写“P90”。

### 6.4 众数与类别频数

众数是最常出现的值，可能没有唯一众数。对连续测量，精确值可能几乎不重复，分箱后众数又依赖箱宽。类别数据更适合报告频数与比例。

## 7. 方差与标准差

方差衡量数据围绕均值的平均平方偏离。总体方差：

```text
σ² = Σ(xi-μ)² / N
```

样本方差常用：

```text
s² = Σ(xi-x̄)² / (n-1)
```

分母不同是因为用途不同。前者描述手头完整总体，后者常作为总体方差的无偏估计。不能不写口径就混用。

### 7.1 完整手算 oracle

对 `[10,20,30,40,50]`，均值 30，偏差 `[-20,-10,0,10,20]`，平方 `[400,100,0,100,400]`，平方和 1000。

```text
总体方差 = 1000/5 = 200
样本方差 = 1000/4 = 250
总体标准差 = sqrt(200) ≈ 14.1421
样本标准差 = sqrt(250) ≈ 15.8114
```

NumPy `np.var` 默认 `ddof=0`，即除以 N；指定 `ddof=1` 才得到常见样本方差。错误往往不是算法不能运行，而是期望口径与参数不一致。

### 7.2 为什么平方

直接求偏差平均会因正负抵消为 0。平方让偏差非负并更重惩罚大偏差，也便于数学优化。代价是方差单位被平方，例如分钟²，不直观；标准差开平方回到原单位。

### 7.3 极端值与稳健离散度

方差对极端值敏感。IQR 或中位数绝对偏差提供更稳健视角。稳健不等于忽略异常：异常可能是数据错误，也可能是关键真实事件。要先审查来源，再决定修复、分层或保留。

## 8. 期望

离散随机变量期望是值按概率的加权平均：

```text
E[X]=Σ x·P(X=x)
```

若一天返修次数 X 取 0、1、2，概率分别 0.2、0.5、0.3：

```text
E[X]=0×0.2+1×0.5+2×0.3=1.1
```

期望 1.1 不必是一次可能观察值；它是长期平均中心。方差可写 `E[(X-E[X])²]`，手算偏差平方加权得到 0.49。

### 8.1 期望的线性

`E[aX+bY]=aE[X]+bE[Y]`，不要求 X 与 Y 独立。方差相加通常需要考虑协方差；独立时某些公式简化。不要把期望的线性错误套到 `E[XY]=E[X]E[Y]`，后者一般需要独立等条件。

### 8.2 期望与样本均值

期望是分布属性，样本均值是从有限样本计算的统计量。反复抽样会得到不同样本均值。样本均值常用于估计期望，但其质量取决于抽样机制、样本量和分布。

## 9. 经验分布与可视化

经验累积分布在每个阈值 t 计算 `样本中 <=t 的数量 / n`。对 `[10,20,30,40,50]`：在 t=25 时为 2/5=0.4，在 t=30 时为 3/5=0.6。它保留所有排序信息，不依赖直方图箱宽。

### 9.1 直方图

直方图把数值分箱并显示频数或密度。箱宽太大隐藏结构，太小则噪声大；不同分箱能让同一数据看起来不同。图必须标轴、单位、样本量、过滤条件和频数/密度口径。

### 9.2 图像不能替代数值 oracle

肉眼看曲线“差不多”不是可复现验证。保存用于作图的排序值、ECDF 数值、分箱边界和计数。教材工件以数值断言为核心；如果额外绘图，应能从保存数据重建。

### 9.3 分层

总体分布可能混合不同设备类型、站点或班次。整体均值掩盖分层差异；分层后样本又可能太少。应同时显示总体与合理分层，并避免在看完结果后反复切分只挑显著差异。

## 10. 抽样与偏差

总体是要回答问题的全部单位，样本是实际观察的一部分。理想样本不只是“大”，还要由能代表总体的抽样机制产生。

### 10.1 选择偏差

只分析已关闭工单会排除仍在处理中、往往耗时更长的工单，得到偏低时长。只选有完整传感器的设备可能偏向新设备。示例 `[10,20,30,40,50]` 总体均值 30；若故意只选 `>=30` 的三条，样本均值 40。计算完全正确，结论仍有偏。

### 10.2 幸存者偏差

只观察仍在线设备，忽略已经故障退出的设备，会高估可靠性。缺失记录不是普通随机缺失时，用剩余数据直接平均会偏。

### 10.3 响应偏差与测量偏差

人工填写时长可能四舍五入，满意用户和不满意用户回应概率不同，传感器校准漂移会系统性改变读数。这些不是增大样本就能消除的随机噪声。

### 10.4 时间偏差与泄漏

用未来才知道的信息描述过去，或随机拆分强时间相关数据，会让离线结果过于乐观。时间窗口必须相对预测/决策时点定义。更完整的数据划分和泄漏将在后续机器学习章节展开。

### 10.5 随机种子不是去偏工具

固定种子使伪随机序列可复现，便于调试；它不让有偏样本变无偏，也不证明结论对其他种子稳健。报告模拟时记录生成器、种子、样本数和容差。

## 11. 模拟与误差容限

假设伯努利概率 p=0.3，固定种子生成 20000 次，经验频率可能得到 0.299。我们在运行前声明允许绝对误差 0.02，随后断言 `abs(freq-0.3)<=0.02`。不能看完结果后才把容差调到刚好通过。

模拟用于验证直觉和程序，不替代理论证明。一次固定种子通过，只说明该确定序列满足 oracle。要研究统计稳定性，应考察多种子、置信区间、样本量和假设，但这超出本章基础工件。

### 11.1 概率和检查

离散分布 `[0.2,0.5,0.3]` 和为 1，且每项非负。`[0.2,0.5,0.4]` 和为 1.1，必须在计算期望前拒绝。不要自动归一化掩盖上游数据错误，除非接口明确声明接收未归一化权重。

### 11.2 浮点容差

概率求和用 `np.isclose`，因为二进制浮点可能不能精确表示十进制小数。容差应很小且声明。容差处理表示误差，不允许负概率或明显偏离 1。

## 12. 相关不等于因果

相关描述两个变量共同变化程度。相关为正表示一个较大时另一个倾向较大，负相关相反，接近零只表示缺少特定线性关系。相关系数不回答“改变 X 会不会导致 Y 改变”。

### 12.1 混杂变量

高温天告警数与维修人数可能同时增加，两者高相关，但高温或负荷是共同原因。观察到多派人时处理量更高，也可能是因为忙碌时本来就派更多人，即反向选择。

### 12.2 反向因果

不是人员多导致故障多，而是故障多导致增派人员。仅凭同时期表格无法确定方向。

### 12.3 选择与聚合效应

总体相关在分组后可能反转，或分组内无相关、混合后出现相关。必须检查分层和数据生成过程。

### 12.4 什么证据更接近因果

随机对照、自然实验、明确时间先后、合理因果图、混杂控制和稳健性分析能增强因果证据，但都需要领域假设。教材实验中即使构造两列完全相关，也只能输出“在此玩具观察表中线性相关为 1；没有干预和混杂控制，不能作因果判断”。

## 13. NumPy 实现合同

```python
import numpy as np

durations = np.array([10, 20, 30, 40, 50], dtype=float)
mean = np.mean(durations)
median = np.median(durations)
q25 = np.quantile(durations, 0.25)
population_variance = np.var(durations, ddof=0)
sample_variance = np.var(durations, ddof=1)
```

入口先验证一维、非空、有限、非负。统计函数默认值不等于业务合同，尤其是分位数方法和方差 `ddof`。输出中保留样本量、单位和口径。

条件概率实现应检查两个布尔向量长度相等、条件计数非零：

```python
numerator = np.count_nonzero(event & condition)
denominator = np.count_nonzero(condition)
probability = numerator / denominator
```

名字直接对应公式，能降低方向颠倒风险。

### 13.1 稳定核心与版本表面

概率公理、条件概率定义、均值/方差公式、期望和抽样偏差属于稳定数学核心。NumPy 函数的参数名、分位数可选方法、随机生成器算法、默认行为和错误文本属于版本表面。

截至 2026-07-24，官方稳定站点为 NumPy 2.5 文档。本仓库工件实际在 Python 3.14.3、NumPy 2.4.4 上验证，没有声称已在 2.5 执行。使用 `np.random.default_rng` 和显式种子，不依赖未声明的全局随机状态；升级后仍应重跑原 oracle。

## 14. 故障分阶段诊断

### 14.1 输入阶段

长度不同、空样本、负时长、NaN 或类别口径不一致，应在统计计算前失败。首证据是输入合同异常及原始小样本。不要让 `nan` 静默传播到最后才看到所有摘要都为空。

### 14.2 统计定义阶段

总体与样本方差混用时，程序会正常运行，首证据是 `ddof` 与手算分母。上例 200 对 250 能明确区分。分位数不一致先看方法和版本，不先修改 oracle。

### 14.3 条件概率阶段

方向或分母选错时，首证据是交叉表的三个计数：条件数、事件数、交集数。先写 `P(event|condition)` 的文字，再代公式。

### 14.4 模拟阶段

频率超容差可能来自种子/生成器改变、样本数不足、p 设置错误或不稳定断言。保留理论 p、样本数、种子和实际频率。一次失败不是自动证明理论错。

### 14.5 解释阶段

把相关说成因果通常不会产生代码异常。首证据是结论文本缺少干预、时间顺序和混杂控制。修复的是论证边界，不是把相关系数换个函数。

## 17. 120 秒复述模板

“样本空间包含可能结果，事件是结果集合；条件概率 `P(A|B)` 把 B 当新样本空间，分母必须是 B。随机变量把结果映射为数值，分布描述各值或区间概率。均值、中位数和分位数描述位置，方差与标准差描述离散；总体方差除 N，常见样本方差除 n-1。期望是概率加权平均，样本均值只是它的有限样本估计。关键证据是逐项手算、明确统计口径、概率和检查与预声明容差模拟。越界反例是看到人员数与维修量相关就说增员必然导致维修量增加；没有干预和混杂控制，相关不能推出因果。”

## 18. 自测题

1. `P(A|B)` 的分母是什么？B 从未出现时为什么不能返回 0？
2. 互斥和独立有什么区别？
3. `[10,20,30,40,50]` 的总体方差与样本方差分别是多少？
4. 中位数比均值稳健，是否意味着永远只报中位数？
5. 分位数为什么必须记录计算方法？
6. 离散概率 `[0.1,0.4,0.6]` 有什么问题？
7. 期望 1.1 为什么可以不是随机变量的可取值？
8. 固定随机种子解决了什么，没解决什么？
9. 只分析已关闭工单可能造成什么偏差？
10. 相关系数为 1 能否单独证明因果？

## 19. 参考答案要点

1. 分母是条件 B 的概率或样本计数；B 不发生时条件比例未定义，0 会伪装成已知结论。
2. 互斥不能同时发生；独立表示知道一个不改变另一个概率，有正概率的互斥事件通常不独立。
3. 平方偏差和 1000，总体 200、样本 250。
4. 不能；二者回答不同问题，应结合分布、尾部、样本量和业务目标。
5. 有限样本插值定义不唯一，不同方法可给不同值。
6. 概率和 1.1，不是合法概率分布。
7. 期望是长期加权中心，不要求本身可观察。
8. 使伪随机实验可复现；不消除抽样偏差，不证明对其他种子和真实总体成立。
9. 排除尚未关闭的长工单，使时长估计偏低。
10. 不能；还需干预/识别假设、时间顺序和混杂控制等证据。
