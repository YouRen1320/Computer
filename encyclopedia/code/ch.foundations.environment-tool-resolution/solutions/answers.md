# 隔离解析：环境、PATH 与工具来源

完成公开练习并保存自己的预测后再阅读。

## A

父为 parent；临时子和其继承环境的孙为 child；子结束后父仍为 parent。环境在创建子进程时传递，不是跨进程共享可变字典。普通未导出 Shell 变量默认不会进入外部子进程环境。

## B

单命令覆盖范围最小、命令结束自然回滚；当前 Shell export 影响该会话后续子进程，关闭会话结束；启动文件可能影响未来特定类型的新 Shell，是持久代码变更。新终端只是重新创建进程并走启动路径，必须比较哪一项环境/配置发生变化。

## C

A:B 时裸命令与 `command -v` 选 A，`type -a` 仍应列 A、B；B:A 反之。绝对 A 入口始终调用 A，不受 PATH 顺序影响。没有候选时故障在 Shell 命令解析/启动阶段，常见状态为 127，但具体诊断按 Shell 合同核对。

## D

裸 java 由 zsh 按 PATH 命中 25；Maven 启动器主动读取 JAVA_HOME 后使用 21。二者消费不同输入，不存在一个抽象“临时变量优先所有配置”。在受控子会话同时把 JAVA_HOME 与 PATH 首项对齐到项目 JDK，再复跑 `type -a`、`java -version`、`mvn -v`。

## E

IDE 与终端是不同父进程和启动入口。分别记录项目 SDK/Runner 启动行与终端 `type -a`/版本。修复后必须从原失败入口复跑，不能用另一入口绿色结果替代。

## F

当前目录优先会造成同名命令劫持；完整环境可能泄露凭据；未知远程脚本和启动文件形成持久执行。替代方案是白名单打印非秘密字段、在 `/bin/zsh -f` 与新临时目录构造固定 A/B 工具、只读观察真实入口，不下载或持久写入。

## G

并存不是故障。为每个项目定义 JDK/工具版本、启动入口、PATH/JAVA_HOME 或项目包装器合同，保存路径与版本证据；通过子会话或受审版本管理方案切换，保留旧合同回滚，不删除 A。
