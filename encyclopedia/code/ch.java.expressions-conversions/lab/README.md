# 实验：整数分金额与溢出边界

目标是用“分”表示本实验中的金额，并验证下面四类输入：

| 场景 | 单价分 | 数量 | 手算预言 |
| --- | ---: | ---: | ---: |
| 正常 | 1,999 | 3 | 5,997 |
| 零数量 | 1,999 | 0 | 0 |
| `int` 内安全上界附近 | 1,073,741,823 | 2 | 2,147,483,646 |
| 会让 `int` 乘法溢出 | 1,073,741,824 | 2 | 2,147,483,648 |

实验中的核心约束是：先把一个操作数提升为 `long`，再乘；不能在已经发生 `int` 溢出后才把结果赋给 `long`。

```bash
cd labs/encyclopedia/ch.java.expressions-conversions
./verify.sh
```

验收条件：

1. `MoneyLabTest` 在启用 `-ea` 时打印 `assertions=8 passed`；
2. 正常、0、安全边界与提升后的溢出输入都等于手算值；
3. `MoneyOverflowProbe` 必须非零退出，日志必须含 `ArithmeticException`；
4. 5,997 分配到 4 组时，每组 1,499，余数 1，并满足“每组×组数+余数=总额”；
5. 最后一行是 `LAB PASS`。

这里的 `assert` 只是已经提供的验证支架，务必使用 `java -ea`；一般方法与正式测试框架会在后续章节系统学习。
