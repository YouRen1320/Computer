# 输入边界红绿实验

先阅读 `src/InputBoundaryLab.java`，预测六个断言。然后运行 `verify.sh`。它用内存中的 stdin 重放合法输入、空行、EOF、非法数字与边界值，不依赖人工键盘速度。

`failures/EofRetryBug.java` 展示一种危险结构：遇到 EOF 后继续循环。验证脚本不会真的让它无限运行，而是检查同构的循环状态并证明“EOF 后仍请求下一次”违反契约。实际调试时不要用反复 Ctrl+C 代替修复。

实验任务：

1. 把成功输出写到 stdout，诊断写到 stderr。
2. 为每种失败返回不同的非零状态。
3. 证明 EOF 路径有限步结束。
4. 把 `1999 3`、`1999 0`、`abc 3`、空行和空输入全部重放。
5. 修复后重新运行原来的全部断言，而不是只跑刚改的一例。
