# 示例：把 AI 输出当作未受信候选

这个示例用静态 JSON 候选模拟 AI 可能给出的补丁。它不调用任何模型，不需要 API key，不联网，也不执行候选代码。`review_model.rb` 只解释一个受限的计价数据模型，目的是让“主张必须由独立、可重复检查验证”可以在普通 Ruby 环境里被证明。

运行：

```bash
ruby examples/encyclopedia/ch.foundations.ai-assisted-verification/verify.rb
```

验证器固定检查：安全任务简报通过；secret 分类的合成上下文在模型使用前被拒；旧回归先绿而新需求 oracle 先红；正常候选被接受；隐藏网络请求、删除负测、伪造成功声明、来源与许可证未知的依赖被拒；所有拒绝项保持工作树摘要不变；接受项可回滚；相同输入两次得到相同报告摘要。

这里的 JSON hunk、敏感信息检测和许可证门禁都是教学模型，不冒充 Git diff、DLP、沙箱、依赖扫描器或法律意见。真实项目仍应审查真实 diff，使用项目测试与安全工具，并按组织政策和法务流程处理第三方代码。
