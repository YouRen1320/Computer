# 最小 DFD 与威胁—控制—验证映射

这个纯 JDK 25 示例为虚构的 FactoryCare 创建工单纵切片建立五个节点、四条数据流和三个信任跨越。六条威胁覆盖 STRIDE，并显式包含认证绕过、越权、篡改、泄露、管理员和内部人。

```bash
./verify.sh
```

验证器检查：每个节点有信任域；跨域流有边界；关键滥用场景齐全；每个威胁都能回指一个控制和一个验证；没有孤儿控制。输出只含计数和布尔值，不含凭据、个人信息或外部连接。

## 教学边界

这是小型 schema，不是完整威胁建模工具。`model_valid=true` 只表示这些显式断言通过，不表示真实系统安全，也不表示 STRIDE 已覆盖隐私、供应链、欺诈或所有内部威胁。FactoryCare 权威模型仍在 `factorycare-design/security/threat-model.md`。
