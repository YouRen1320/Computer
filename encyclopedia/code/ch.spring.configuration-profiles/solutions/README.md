# 外部配置优先级：私有参考答案

参考实现把 `SystemEnvironmentPropertySource` 放在默认值属性源之前。解析器按顺序返回第一个匹配值，因此环境变量覆盖默认值，而环境未提供该键时仍能回退到默认端点。

运行：

```bash
./verify.sh
```

验收输出应为 2 个测试全部通过并显示 `SOLUTION PASS`。验证器固定使用 Spring Boot 4.1.0、JDK 25、Maven 3.9.16，且 Maven 只以离线模式运行。

该答案只演示可控属性源的优先级与环境变量名称映射；它不读取开发机真实环境，不涉及 Profile 业务分支，也不保存任何秘密。
