## A. 分层判断

1. `api.factorycare.example` 能解析出 IP，但连接 `443` 立即被拒绝。哪些层有证据，哪些层没有？
2. TCP 已连接，证书链受信任，但证书 SAN 不含请求主机名。应归到哪层？为什么不能说 DNS 错？
3. `ping` 有回复，但业务客户端仍失败。列出至少三个尚未被 `ping` 证明的条件。
4. 同一 IP 上 `443` 成功、`8443` 拒绝，说明 IP、主机、端口三者是什么关系？

## B. 证据排序

## C. 拒绝与超时

1. 用一句话分别解释“立即拒绝”和“等待超时”的可观察差别。
2. 为什么不能仅凭超时断定“服务器宕机”？列出路由、防火墙、监听、资源拥塞和错误目标中的可能性。
