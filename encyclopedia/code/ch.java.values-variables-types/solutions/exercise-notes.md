# 教师用解析：值、变量、类型与作用域

本文件与公开练习隔离。只有学习者已经提交预测和实现，或明确退出独立测评后，才用于批改。

## B 组判定要点

- B1：编译并运行，重新赋值后只打印变量当时的当前值。
- B2：编译失败；普通局部变量读取前必须明确赋值，不能套用字段默认值。
- B3：编译失败；`label` 的作用域在内层块末尾结束。
- B4：合法；两个 `count` 的作用域不重叠。
- B5：编译失败；外层 `count` 仍在作用域内，Java 不允许内层重声明同名局部变量。
- B6：编译并运行；第一组 `print` 与 `println` 连成一行，`printf` 的 `%n` 结束下一行。

批改时必须要求学习者提供先写的预测，不能仅凭最终运行结果计为独立完成。

## D 组判定要点

- 前四项应在 `javac` 编译阶段失败，分别定位到明确赋值、作用域、类型不兼容和重复局部声明。
- 第五项通常通过编译，在执行 `printf` 时因格式符与参数类型不匹配而抛出格式化异常。
- 合格诊断需要包含实际文件行列和修复后重跑，不只写错误名称。

## E 组判定要点

四值状态已经不是二选一，单个 `boolean` 无法完整表达。尚未学习 enum 时可以用 `String` 做受限练习，但必须标明这是过渡表示；最终应由后续状态建模约束合法值，不能让任意文本成为领域状态。

## 评分观察

1. 是否把 `String` 误列为基本类型；
2. 是否认为局部 `int` 自动为 `0`；
3. 是否把 Java 局部同名失败套用成 JavaScript 的合法块遮蔽；
4. 是否只看 `BUILD SUCCESS`，没有核对输出；
5. 是否能在不重新生成整类的情况下完成需求变更；
6. 是否在示例或日志中加入真实敏感数据。
