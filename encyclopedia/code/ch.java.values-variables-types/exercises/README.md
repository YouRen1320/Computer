## C. 独立构建

从空白文件创建 `InspectionSnapshot.java`，满足以下契约：

- 使用 `long` 保存检查记录 ID `900000001L`；
- 使用 `String` 保存设备名称 `C区-配电柜-03`；
- 使用 `int` 保存异常项数量 `1`；
- 使用 `boolean` 保存是否需要复检 `true`；
- 使用 `char` 保存区域代码 `'C'`；
- 先把状态文本初始化为 `待提交`，再赋值为 `已提交`；
- 在内层代码块中声明并输出检查阶段 `现场检查`；
- 至少各使用一次 `print`、`println` 和 `printf`；
- 运行前写出逐行预期，运行后用 `diff` 比较，不凭肉眼说“差不多”。

你需要提交源码、预期输出、实际输出、构建命令和退出码。
