# 私有解析：日志安全与证据门禁

解析采用字段键允许/敏感集合、受控 correlation 正则和显式样本下限。它不读取外部状态，也不把样本下限冒充根因算法。

核对时说明：

- 键先转小写并把连字符改为下划线，避免 `Authorization` 绕过；
- 返回新 `LinkedHashMap`，保留确定顺序且不修改输入；
- correlation 正则排除 CR/LF，仍不能用于授权；
- 两张 dump 只允许讨论“跨样本持续”，不能自动证明死锁；
- 5 个样本与一次 warmup 是教学门禁，生产性能应使用 JMH/代表性负载和统计报告。

```bash
./verify.sh
```
