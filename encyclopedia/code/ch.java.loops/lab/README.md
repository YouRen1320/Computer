# 实验：0、1、N 与终止边界

本实验用固定整数 N 验证循环的三个最小边界：0 次、1 次与多次。没有数组或控制台输入，循环状态全部能手算。

| 场景 | 预期 |
| --- | --- |
| `N=0` 的 `for` | 0 次，和为 0 |
| `N=1` 的 `for` | 1 次，和为 1 |
| `N=4` 的 `for` | 4 次，和为 10 |
| 从 3 递减的 `while` | 3 次，最终 0 |
| 初始上限为 0 的 `do-while` | 仍执行 1 次 |
| 哨兵从 3 变到 0 | 处理 3 次并终止 |
| 1..5 中跳过 2、遇 5 停止 | 处理 1、3、4，共 3 次，累积 8 |

```bash
cd labs/encyclopedia/ch.java.loops
./verify.sh
```

验收条件：正常程序七行输出精确匹配；固定 oracle 在 `-ea` 下显示 `assertions=10 passed`；遗漏更新的探针被安全预算阻断并非零退出；最后一行是 `LAB PASS`。
