# 循环状态观察台

这个最小工程只依赖 JDK 25，不使用数组、集合、递归或控制台输入。它用整数状态展示 `for`、`while`、`do-while`、计数器、累加器、哨兵、`continue` 与 `break`。

运行前先预测：

1. `for (int i = 1; i <= 3; i++)` 的第一次、最后一次与循环后 `i` 的边界；
2. 1+2+3 的累积结果；
3. 从 3 递减到 0 的 `while` 执行几次；
4. 初始条件已经不满足时，`do-while` 为什么仍执行一次；
5. 扫描 1..6 时跳过 2、遇到 5 停止，真正处理多少项。

```bash
cd examples/encyclopedia/ch.java.loops
./verify.sh
```

脚本会逐行核对正常输出，并运行一个故意遗漏状态更新、但带四步安全预算的探针。探针必须非零退出且打印 `NON_TERMINATING_GUARD`；安全预算使实验可重放，而不会真的把终端永久卡住。
