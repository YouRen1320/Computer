## A. 镜像与容器

解释镜像层、容器可写层和容器主进程。为什么“删除容器”不等于“删除镜像”，也不一定等于“删除数据”？

## B. 端口

应用监听容器内 8080，命令只写 `EXPOSE 8080`，主机访问 `localhost:18080` 失败。列出监听、publish、主机 IP 与防火墙四层证据。

## C. named volume 与 bind mount

分别写出适用场景、所有者、可移植性和安全风险。为什么把宿主 `/` 可写挂进容器是危险反例？

## D. 挂错路径

volume 实际挂到 `/var/lib/factorycare-data`，应用写 `/var/lib/factorycare/data`。容器运行时“看起来有文件”，重建后却丢失。用 inspect、logs 和文件证据定位。

## E. 网络

同一用户定义 bridge 中，API 是否需要把数据库端口发布到主机才能按容器名访问数据库？为什么容器 `localhost` 不是另一个容器？

## F. 清理

比较逐项 `stop`/`rm`、`--rm` 和全局 `prune` 的影响。为教学实验写资源所有权与回滚清单。

## G. 故障闭环

设计端口未发布、卷挂错目标、无卷重建丢数据三个故障，写 expected、首个可信证据、修复和恢复复跑。
