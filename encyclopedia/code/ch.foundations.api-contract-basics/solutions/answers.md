# 隔离解析：API 资源、错误、版本、分页、缓存与幂等语义

完成公开练习并保存预测后再阅读。

## A 组

资源是被 API 标识和操作的概念；JSON 只是某时、某媒体类型、某版本下的表示。数据库行受存储与内部实现约束，可能含租户键、软删除、审计或秘密字段，不能直接成为公开合同。最小设备表示可含稳定 ID、显示名、公开状态；内部表名、凭据、维护备注和实现堆栈不公开。

## B 组

公开 Problem 可含稳定 type/code、通用 title、status、可行动 detail 与 opaque instance/关联号。SQL、类名、路径、堆栈、凭据和表结构只进受控内部日志。两侧以不可猜测且不含秘密的关联标识连接，客户端不能凭关联号读取未授权详情。

## C 组

新增可选字段通常可兼容能够忽略未知字段的消费者；删除/改名直接破坏旧字段依赖；枚举扩大可能让穷举客户端失败；整数变字符串改变类型；null 与缺失互换可能改变业务含义。每项都要用真实消费者契约验证，不能只看路径版本。

## D 组

第一页 `D,C`。插入 E 后全序为 `E,D,C,B,A`，offset=2 得 `C,B`，重复 C；after-C 得 `B,A`。游标需要稳定、确定、最好含唯一 tie-breaker 的排序键，并规定无效、过期和权限变化行为。Base64 只是不透明表示，不提供防篡改。

## E 组

匹配时可返回 304，携带相关 ETag，且没有新的表示 Body。客户端复用自己已有的 200 Body；304 不是“资源内容为空”，也不能在没有缓存副本时单独还原资源。

## F 组

无保护重试可能创建两条；同键同 payload 应得到同一逻辑结果且资源数仍为一；同键不同 payload 应明确冲突，不能悄悄复用或再建。幂等记录与业务写入在生产中还需事务/并发原子性，本章内存模型未证明该项。

## G 组

可先保持旧字段，新增可选 location；把内部异常统一映射公开 Problem；新增游标模式并让旧页码客户端按明确期限迁移；创建端要求每次逻辑操作稳定键。回滚保留旧表示读取、停止新写入路径或恢复旧分页入口，但不能回滚已创建业务数据。非目标包括鉴权、数据库事务、代理缓存和多租户权限。
