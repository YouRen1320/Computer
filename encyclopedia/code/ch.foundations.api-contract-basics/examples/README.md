# 示例：用纯内存模型验证 API 契约

本示例不启动 HTTP 服务，不连接数据库，也不实现路由、鉴权或事务。Ruby 只是承载固定输入与断言，学习重点是外部可观察契约。

运行：

```bash
ruby verify.rb
```

预期最后一行是 `api-contract-basics verification: PASS`。验证器同时证明：

- v1 表示在 v1.1 增加字段后仍保持旧字段和值，重命名旧字段会被拒绝；
- 未知内部异常映射为稳定 Problem，不泄露类名、堆栈或内部错误文字；
- 插入新数据后，页码/offset 会重复 `C`，固定排序键游标仍得到 `D,C` 后接 `B,A`；
- 最后一页之后返回空 `items` 与空游标，非法游标得到稳定错误；
- 首次读取返回 ETag，相同验证器再次读取得到 304 与空 Body；
- 无幂等保护的重试创建两个 ID；同一键和同一请求只保留一个 ID，同一键换请求得到 409。

示例中的域名、设备、工单和幂等键均为虚构值。游标只要求客户端不解释，不宣称 Base64 能提供保密性或防篡改；生产实现还需签名、过期和权限设计。
