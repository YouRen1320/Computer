# 独立练习：从失败证据修复 SLA 余量

规则：`remainingMinutes(targetMinutes, elapsedMinutes)` 应返回目标减去已用时间。starter 故意使用加法，正常输入测试会失败，零输入恰好通过。

步骤：先预测失败数量；运行 `bash verify.sh`；只看第一处项目测试位置及 expected/actual；手算 `60 - 15`；在业务方法设置断点观察两个参数；只改一处运算；重跑同一脚本。脚本能识别“已复现 starter 故障”和“修复后两条全绿”两种可信状态。

提交诊断记录时分开写事实、推断与修复：事实是日志中的阶段和数值；推断是运算符可能错误；修复是把加法改回契约要求的减法。
