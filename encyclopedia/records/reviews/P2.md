## 已实施关闭

### Fail-closed 机器契约

- 三份 JSON Schema 由受控 Draft 2020-12 执行器实际运行；支持 boolean schema、`$ref` sibling、`allOf`、boolean `items`/`if`/`then` 等仓库使用子集。
- 未支持关键字、坏定义、坏引用、未知 format 均失败；严格 JSON object class 在任意层级拒绝重复成员。
- 所有课程 YAML、registry/site 配置和 front matter 在反序列化前遍历 Psych AST，拒绝所有层级重复 mapping key、复杂 key 和 alias。
- 直接运行 `validate-encyclopedia.rb` 时，由它调用严格 `curriculum/validate_catalog.rb`；builder 只调用这个单一入口，避免双份严格规则或递归。

### Canonical input 与路径

- 在读取 schema、registry、catalog 或执行严格 validator 之前，先用 `RepositoryPathPolicy` 预检 canonical input。
- catalog、registry、site config、三份 schema、strict/build/validator 脚本、routes、gates、`ASSESSMENTS.md`、`PROGRESS.md`、全部章文件与卷 README 均须为仓库内普通文件，任一路径组件为 symlink 即失败。
- review/verified 的工件只能位于本章 `examples`、`labs`、`exercises`、`solutions-private` 子树；普通文件必须含非空白内容，目录必须至少含一个非隐藏、非空白普通文件，并拒绝目录后代 symlink。
- 所有 gate、publication coverage 和版本 evidence 只能位于 `records/encyclopedia/evidence/`，必须是非空白普通文件。

### 内容、身份和依赖门

- `review` 与 `verified` 都禁止架构占位、缺正文和 standalone TODO/TBD，至少有两个 H2，规范化正文至少 200 字符。
- `verified` 除正文门外，还要求五个强制门 passed、安全/无障碍受控 N/A、publication/navigation 三类覆盖，以及全部硬前置传递闭包已 verified。
- 作者/reviewer Unicode trim 后至少两个字符；独立性比较使用 NFKC + Unicode casefold，拒绝全角/大小写/外围空白伪装的自审。
- 七门为 `technical`、`pedagogical`、`code`、`security`、`accessibility`、`version_sources`、`publication_navigation`。

### 版本与来源

- registry、catalog、site edition 必须一致。
- registry `source_url` 与 chapter `source_refs.url` 必须解析为 HTTPS、host 非空、userinfo 为空；允许 fragment 指向官方文档精确章节。
- `source_refs.id` 章内唯一；`verified_versions.constraint` 必须逐字匹配 registry 对应约束，实际 patch 记录进入真实 evidence。
- 所有 registry、章节、来源、gate 日期均拒绝未来日期。

### 私有解析与确定性发布

- 旧 `answers_path` 无兼容迁移为非空 `solutions_private` 数组；`solutions-private/` 明确排除于公开 manifest 和五个输出。
- manifest 现覆盖严格 validator 实际读取/扫描的 `ASSESSMENTS.md`、`PROGRESS.md`、全部 `book/`/`curriculum/` 规范文件，以及 schema、版本、站点、构建器和达到 review/verified 后的公开工件与证据。
- manifest 保存逐输入 SHA-256 和四个非 manifest 输出摘要；相同输入重复构建字节一致。
- `--check` 用同一 renderer 重算并拒绝缺失、篡改、额外文件、目录或 symlink；正常构建 staging 后整体替换输出。
