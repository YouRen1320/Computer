# 深度学习：神经网络、反向传播与 Transformer

## 1. 神经网络是许多可学习函数的组合

最基本的一层先做加权和，再经过非线性函数：

```text
z = XW + b
a = activation(z)
```

训练的目标是找到合适的权重 `W` 和偏置 `b`，让模型在未见数据上完成任务。它不是模拟完整人脑，而是一类可微分函数模型。

## 2. 一个神经元从线性单元开始

```text
z = w₁x₁ + w₂x₂ + ... + b
```

每个权重控制一个输入对分数的影响，偏置移动整体门槛。只有线性层叠仍然只是线性变换，因此需要激活函数引入非线性。

## 3. 批量输入让多个样本一起计算

```text
X：(batch, input_features)
W：(input_features, output_features)
b：(output_features,)
Z = X @ W + b：(batch, output_features)
```

偏置沿批次轴广播。每一层都应写清 shape，不要只靠运行报错发现维度问题。

## 4. ReLU 保留正值并截断负值

```text
ReLU(z) = max(0, z)
```

它计算简单，常用于隐藏层。负区间梯度为零，某些单元可能长期不激活。激活选择会影响梯度传播和表示能力，不是外观选项。

## 5. Sigmoid 把数值压到 0 到 1

```text
sigmoid(z) = 1 / (1 + e^(-z))
```

它常用于二分类输出概率。绝对值很大的区域梯度接近零，深层隐藏层大量使用时可能导致梯度消失。

概率输出仍需校准和阈值决策，不能把 0.9 自动解释成业务事实。

## 6. Softmax 把一组分数变成概率权重

对同一行的类别分数：

```text
softmax(zᵢ) = exp(zᵢ) / Σⱼ exp(zⱼ)
```

结果非负且和为 1。为避免指数溢出，实际计算通常先减去该行最大值。最关键的合同是在哪个轴上归一化。

## 7. 前向传播计算预测

```text
输入 X
  → 线性层 Z₁
  → 激活 A₁
  → 线性层 Z₂
  → 输出概率/数值 ŷ
```

前向过程同时产生反向传播所需的中间值。训练时保留计算图，推理时通常不需要梯度图。

## 8. 损失函数把预测误差变成可优化的数

回归可用均方误差，二分类常用二元交叉熵，多分类常用交叉熵。损失函数定义“训练时怎样算错”，业务指标定义“上线后怎样算有用”。

两者可以不同，但方向应相关。损失归约用 sum 还是 mean 会改变梯度尺度。

## 9. 交叉熵重罚给真实类别过低概率

若真实类别概率为 `p`，单样本负对数损失可写为：

```text
loss = -log(p)
```

当 `p` 接近 1，损失接近 0；当 `p` 接近 0，损失快速变大。实现通常直接接受 logits，以获得更稳定的合并计算，不应重复手工 Softmax。

## 10. 反向传播是链式法则的高效组织

损失由许多中间计算组成。反向传播从损失开始，沿计算图反向复用局部导数，得到每个参数对损失的梯度。

```text
参数 → 中间激活 → 预测 → 损失
梯度 ← 局部导数相乘/相加 ←
```

它不会决定如何更新参数，更新由优化器负责。

## 11. 参数梯度与激活梯度不同

参数梯度用于更新 `W`、`b`；激活梯度用于继续把影响传到更早层。查看调试信息时要知道当前张量代表参数、输入、激活还是损失。

只看一个总梯度范数可能掩盖某层全零或某些参数爆炸。

## 12. 梯度在多条路径汇合时需要相加

一个值若同时影响后面两个分支，损失对它的总影响是两条路径贡献之和。漏掉其中一条就是常见手算和自定义反向实现错误。

计算图让自动微分系统记录这些依赖。

## 13. 梯度下降沿负梯度方向更新

```text
parameter = parameter - learning_rate × gradient
```

减号写反会让损失上升。学习率控制步长；太大可能发散，太小可能极慢。训练曲线异常时先查数据、损失、梯度和更新顺序，再盲目调学习率。

## 14. SGD 用当前批次梯度更新参数

随机梯度下降通常使用 mini-batch，而非每次只用一个样本或完整数据。批次带来带噪但便宜的梯度估计。

批次大小会影响梯度噪声、显存、吞吐和归约尺度，改变时不能假设其他超参数无需调整。

## 15. Momentum 利用过去更新方向

Momentum 累积梯度的移动方向，在狭长损失谷中减少左右震荡并加快一致方向移动。

它引入额外优化器状态。恢复训练时只加载模型权重却不加载优化器状态，后续轨迹不会真正延续。

## 16. Adam 自适应不同参数的更新尺度

Adam 维护梯度一阶和二阶统计，常是易用起点，但不保证对所有任务最好。学习率、权重衰减和数值稳定仍需验证。

优化器选择不能修复数据泄漏和错误标签。

## 17. 权重衰减和梯度裁剪解决不同问题

权重衰减限制参数规模，偏向更简单解；梯度裁剪限制单次梯度过大，常用于序列模型稳定训练。

裁剪能缓解症状，但若持续触发，应调查数据、损失、归约、学习率和数值异常。

## 18. 梯度消失让早期层几乎学不到

多层链式相乘时，如果许多局部导数小于 1，传到前面的梯度可能接近零。饱和激活、过深网络和不当初始化都会加重。

残差连接、归一化、合适激活和初始化能改善信号传播。

## 19. 梯度爆炸让数值迅速失控

若局部导数反复大于 1，梯度可能变得极大，导致参数、损失出现 `inf` 或 `nan`。

防线顺序通常是：检查输入和标签、检查损失归约、记录每层梯度、调整初始化/学习率，再考虑裁剪。

## 20. 初始化影响训练起点和信号尺度

所有权重都初始化为同一个值会让同层单元保持对称，学不到不同特征。常用初始化根据输入/输出维度控制方差。

随机种子有助于复现同一环境，但不同硬件、算子和并行方式仍可能产生差异。

## 21. 训练模式和推理模式影响层行为

Dropout 在训练时随机屏蔽部分激活，推理时关闭；BatchNorm 在训练和推理使用不同统计方式。因此必须正确切换模式。

模式切换与是否计算梯度是两件事：推理通常既要 eval 模式，也要关闭梯度记录。

## 22. 过拟合表现为训练继续改善而验证恶化

可能的缓解方式包括更多可靠数据、减小模型、正则化、数据增强和早停。但首先检查训练/验证预处理是否一致、划分是否合理和指标是否同口径。

测试集不参与这段诊断。

## 23. 序列数据需要表示顺序

文本、事件流和传感器时间序列的顺序会改变含义。把 token 只映射成向量并作为无序集合处理，会丢失位置信息。

Transformer 会把位置编码或位置机制加入表示，让模型区分先后和距离。

## 24. Token 是模型处理的基本离散单位

Token 可以是词、子词、字符片段或其他符号。Tokenizer 把原始文本转成 token ID，Embedding 再把 ID 映射成向量。

Token 数不等于汉字数或单词数。上下文长度、成本和截断都按模型 tokenizer 的 token 规则计算。

## 25. Embedding 是可学习的向量表示

每个 token ID 查到一个向量。训练使在任务中作用相近的模式形成有用几何结构。

向量相近只表示模型表示中的相似，不自动等于事实相同、因果相关或伦理上可互换。

## 26. 注意力让每个位置按相关程度汇总其他位置

每个 token 产生三组向量：

```text
Query：当前这个位置想找什么
Key：每个位置提供什么匹配线索
Value：匹配后实际汇总什么内容
```

Query 与 Key 计算匹配分数，Softmax 把分数变成权重，再对 Value 做加权和。

## 27. 缩放点积注意力有清晰的形状流程

```text
Q：(batch, heads, query_length, d_k)
K：(batch, heads, key_length, d_k)
V：(batch, heads, key_length, d_v)

scores = Q @ Kᵀ / sqrt(d_k)
weights = softmax(scores, axis=key_length)
output = weights @ V
```

除以 `sqrt(d_k)` 防止维度较大时点积分数过大，让 Softmax 过度饱和。

## 28. Mask 必须在 Softmax 前排除不可见位置

Padding mask 排除补齐位置；causal mask 防止生成位置看见未来 token。通常把被遮位置分数设为非常小，再做 Softmax。

若先 Softmax 再把权重乘零，剩余权重不再和为 1。全遮蔽行还可能产生 NaN，需要显式策略。

## 29. 自注意力和交叉注意力来源不同

自注意力的 Q、K、V 来自同一序列，让各位置互相汇总。交叉注意力的 Query 来自一个序列，Key/Value 来自另一个来源，如解码器查询编码器输出。

两者计算形式相似，数据来源和可见性合同不同。

## 30. 多头注意力提供多个表示子空间

模型把特征拆成多个 head，各自计算注意力，再拼接和投影。不同 head 有机会学习不同关系，但不保证每个 head 都有清晰的人类语义。

head 数、每头维度和总模型维度必须形状一致。

## 31. 残差连接保留原信号和梯度通道

```text
output = input + sublayer(input)
```

它让子层学习对原表示的修正，也给深层网络提供较直接的梯度路径。相加要求形状兼容。

## 32. Layer Normalization 稳定每个 token 的特征尺度

LayerNorm 通常沿特征维归一化，与 BatchNorm 的批次统计不同，更适合可变序列和小批次。

具体是 pre-norm 还是 post-norm 会影响训练稳定性和架构行为，阅读模型时应看清顺序。

## 33. 前馈网络对每个位置独立变换

注意力在位置之间混合信息，位置前馈网络对每个 token 的特征做相同非线性变换：

```text
hidden = activation(xW₁ + b₁)
output = hiddenW₂ + b₂
```

两者与残差、归一化共同组成 Transformer block。

## 34. 编码器和解码器承担不同角色

编码器可让每个位置看整个输入，适合理解和表示。自回归解码器使用 causal mask，只根据前文预测下一个 token。编码器—解码器结构还用交叉注意力连接输入与输出。

现代模型可以只用编码器、只用解码器或组合，不能把 Transformer 等同于某一种产品形式。

## 35. 自回归生成是反复预测下一个 token

```text
已有上下文 → 得到下一个 token 概率
选择一个 token → 加入上下文
再次前向 → 继续生成
```

贪心、温度、top-k、top-p 等采样策略改变选择方式。生成结果有随机性和累积误差，不是从数据库直接读取事实。

## 36. 上下文窗口是有限工作区

输入、工具结果和模型输出都占 token。超过上下文上限时必须截断、摘要或检索相关片段。

“放得进去”也不表示模型会同等利用每个位置。长上下文仍需信息结构、引用和评估。

## 37. 注意力计算对序列长度成本敏感

标准全注意力的分数矩阵大小随序列长度平方增长。长文档会增加显存、延迟和成本。

分块、检索、稀疏/窗口注意力和缓存等方案各有取舍，不能只靠提高上下文上限解决所有问题。

## 38. 注意力权重不是可靠因果解释

某位置权重高，说明当前计算中被较多汇总，不等于它“导致”最终决定，也不证明模型按人类语义理解。

解释需要反事实、干预、错误分析和领域审查等多种证据，不能只画一张注意力热图。

## 39. 深度学习调试从小而确定的例子开始

```text
固定一个极小批次
  → 检查输入/标签 shape 和范围
  → 手算或独立计算前向损失
  → 检查梯度是否有限、是否缺失
  → 确认一次更新方向
  → 尝试过拟合这个小批次
  → 再扩大数据和模型
```

小批次都无法拟合时，先查实现和数据，不应直接增加层数。

## 40. Transformer 的安全边界不由模型结构自动解决

模型能生成流畅文本，但仍可能编造事实、泄露上下文、服从恶意指令或输出不安全动作。结构化输出、检索、权限、工具审批和人工复核属于系统层控制。

模型参数中的知识没有可审计来源，重要业务结论需要外部证据和引用。

## 41. 这一阶段应形成的整体地图

```text
输入张量
  → 线性变换 + 激活
  → 前向预测 + 损失
  → 反向传播得到梯度
  → 优化器更新参数

序列：token → embedding + position
  → Q/K/V 注意力 + mask
  → 残差 + LayerNorm + 前馈
  → 多层 Transformer → 下一个 token/任务输出
```

必须掌握：非线性让多层网络有表达能力；损失不等于业务指标；反向传播是链式法则；梯度和优化器状态要分清；train/eval 与是否求梯度是两组开关；Softmax 的轴是合同；mask 必须在归一化前应用；上下文和注意力都有成本；流畅生成不等于可靠事实。

具体网络架构和训练技巧变化很快；实现时以所用框架、模型论文和官方说明为准，并用小型独立样本验证 shape、数值和梯度。
