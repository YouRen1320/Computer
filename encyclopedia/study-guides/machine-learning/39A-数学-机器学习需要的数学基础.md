# 数学：机器学习需要的数学基础

## 1. 机器学习数学的目标是看懂数据、模型和误差

这一阶段不追求把所有定理证明一遍，而是建立四种能力：

- 能给数量写清单位和范围；
- 能看懂向量、矩阵和形状；
- 能理解概率、均值、方差和抽样偏差；
- 能理解损失怎样通过梯度改变参数。

数学式不是装饰，它是业务假设的压缩表达。

## 2. 数值必须连同单位一起理解

`30` 可能是分钟、小时、元或摄氏度。相加前单位必须相同，相除后单位会变化：

```text
成本（分） = 单价（分/件） × 数量（件）
响应速度（工单/小时） = 完成工单数 ÷ 小时数
```

量纲检查能很便宜地发现公式方向错误，但不能证明业务规则本身正确。

## 3. 精确值和近似值要分开

工单数量是离散精确整数，传感器温度通常是带误差的近似测量。金额可以用最小货币单位整数表示，概率和平均值常用浮点近似。

舍入应发生在明确边界，例如最终展示，而不是每个中间步骤都随意四舍五入。

## 4. 百分比变化与百分点变化不同

故障率从 10% 降到 8%：

```text
下降 2 个百分点
相对下降 (10% - 8%) / 10% = 20%
```

两种说法都可能正确，但回答不同问题。指标报告必须说明分母和基准。

## 5. 比率和比例都要写清分子分母

“每百台设备的故障数”不是单纯故障总数。两个工厂规模不同，只比较总数会误导。

任何比率都问：观察单位是什么、时间窗口是什么、分母是否为零、分母太小时是否稳定。

## 6. 变量和公式表达输入到输出的关系

```text
C = P + R × H
```

其中 `C` 是估价，`P` 是零件成本，`R` 是每小时人工费，`H` 是工时。公式应附变量表、单位、允许范围和舍入规则。

把需求翻成公式时，先写文字关系，再替换为符号，最后用简单数值手算核对。

## 7. 方程是在已知关系中求未知量

如果 `C = P + R × H`，已知其他量后可求：

```text
H = (C - P) / R
```

变形时对等式两边执行相同操作，并检查定义域，例如 `R` 不能为零。代回原式是最便宜的核对方式。

## 8. 不等式表达范围和门槛

```text
0 ≤ confidence ≤ 1
priority ≥ 4
response_minutes < SLA_minutes
```

特别注意 `<` 与 `≤` 的边界。模型阈值规则和业务 SLA 都容易在等号处出现偏一错误。

## 9. 估算和数量级是结果的快速防线

如果 3 件商品每件约 20 元，总价应约 60 元。程序输出 6000 元，即使类型和退出码都正常，也应该立即怀疑单位或小数点。

复杂模型同样需要朴素上限、下限和常识基线。

## 10. 函数表示每个允许输入对应一个输出

记作 `y = f(x)`。定义域说明允许哪些输入，值域说明可能产生哪些输出。

例如 `log(x)` 只对正数定义，概率输出应在 0 到 1 之间。模型代码在进入运算前要检查这些前提。

## 11. 同一个函数可以用四种方式表示

```text
文字：每增加一小时，成本增加固定费率
公式：C(H) = P + R × H
表格：不同 H 对应的 C
图像：横轴 H，纵轴 C
```

四种表示应彼此一致。表格适合核对样本，图像适合看趋势，公式适合推导和实现。

## 12. 斜率表示输入变化一单位时输出变化多少

直线 `y = ax + b` 中，`a` 是斜率，`b` 是截距。

```text
斜率 = Δy / Δx
```

斜率有单位。例如成本对工时的斜率单位是“分/小时”。截距是 `x=0` 时的模型输出，不一定在现实中有合理含义。

## 13. 分段函数表达不同区间使用不同规则

加急费、阶梯价和 SLA 惩罚经常是分段规则。每个区间必须说明端点是否包含：

```text
0 ≤ hours ≤ 2
2 < hours ≤ 8
hours > 8
```

图像在边界处不连续不一定是 bug，可能就是业务政策；关键是合同明确。

## 14. 指数描述按比例反复变化

```text
y = a × b^t
```

当 `b > 1` 是指数增长，`0 < b < 1` 是指数衰减。复利、放射衰减和某些学习率计划都使用这种结构。

指数变化很快，先看数量级，避免把线性直觉套在指数过程上。

## 15. 对数回答“指数需要多少次”

若 `b^t = y`，则 `t = log_b(y)`。机器学习中自然对数常出现在交叉熵，底为 10 的对数常用于数量级展示。

对数输入必须为正。对数变换可能让长尾数据更易观察，但会改变差值解释，不应只为图像好看而使用。

## 16. 求和符号表示把一组项加起来

```text
Σᵢ xᵢ = x₁ + x₂ + ... + xₙ
平均值 = (1/n) Σᵢ xᵢ
加权和 = Σᵢ wᵢxᵢ
```

实现时明确索引范围、元素数量和是否取平均。批次损失用 sum 还是 mean 会改变梯度尺度。

## 17. 标量、向量、矩阵和张量是不同形状的数据

```text
标量：一个数
向量：一列或一行特征
矩阵：样本 × 特征
张量：更多轴，如批次 × 时间 × 特征
```

“张量”是多维数组的通称。阶数表示轴的数量，shape 表示每个轴的长度。

## 18. 形状应同时写出业务轴标签

`(32, 10)` 本身不够，应该知道它是 `(batch=32, features=10)` 还是 `(time=32, sensors=10)`。

运算前写输入 shape，运算后预测输出 shape。形状正确仍可能把轴语义交换，所以标签也要检查。

## 19. 向量逐元素乘法和点积不同

给两个向量 `x`、`w`：

```text
逐元素乘法：[x₁w₁, x₂w₂, ...]
点积：x·w = Σᵢ xᵢwᵢ
```

线性模型常用点积把多个特征加权成一个分数。点积要求长度相同，结果是标量。

## 20. 向量长度、距离和相似度回答不同问题

欧氏长度衡量从原点到向量的直线距离。两个向量相减后的长度可表示距离。余弦相似度主要比较方向，弱化整体大小。

选择距离前要考虑特征单位和缩放。以元计的金额和 0/1 标志直接计算欧氏距离时，金额很可能完全支配结果。

## 21. 矩阵乘法组合“加权再求和”

若 `X` 形状为 `(batch, features)`，`W` 形状为 `(features, outputs)`：

```text
X @ W → (batch, outputs)
```

中间维度必须相同，外侧维度成为结果形状。矩阵乘法通常不能交换次序：`X @ W` 与 `W @ X` 既可能形状不合法，也可能含义完全不同。

## 22. 转置、重塑和换轴不是同一件事

转置或换轴改变轴顺序；reshape 只按内存中的元素重新解释形状。把 `(batch, time, features)` 变成 `(time, batch, features)` 需要换轴，不是随意 reshape。

在代码评审中看到 reshape，应问元素顺序是否仍符合业务含义。

## 23. 广播让某些维度自动扩展

给每个样本加同一个偏置向量：

```text
X：(batch, features)
b：(features,)
X + b：(batch, features)
```

广播规则能省去复制，但也会让错误 shape 合法运行。最危险的不是立刻报错，而是产生看似合理的更大矩阵。

## 24. 概率是在明确模型下描述不确定性

概率在 0 到 1 之间，同一完整样本空间中的互斥结果概率之和为 1。它可能来自理论模型，也可能用历史频率估计。

模型输出的 0.8 不自动等于现实中 80% 会发生，还要检查校准、数据分布和适用范围。

## 25. 条件概率表示已知信息后的概率

```text
P(A | B) = P(A 且 B) / P(B)
```

例如“已知机器停机时，工单为关键级的概率”。分母是满足条件 B 的样本数，不是全部样本数。

`P(A|B)` 与 `P(B|A)` 通常不同，这正是许多直觉错误的来源。

## 26. 独立表示一个事件不改变另一个事件的概率

若 A 与 B 独立，则 `P(A|B)=P(A)`。现实业务数据中的设备、站点、时间通常彼此相关，不能为了方便默认独立。

同一设备的多条工单放进训练集和测试集，会破坏样本独立直觉并造成泄漏。

## 27. 随机变量把随机结果映射成数值

伯努利分布描述一次成功/失败；二项分布描述固定次数中的成功数；正态分布常用于连续噪声近似；泊松分布可描述某时间窗事件数。

分布是建模假设，不是看到钟形图就能宣布“正态”。应检查生成机制和数据证据。

## 28. 均值、中位数和分位数描述不同位置

- 均值利用所有数值，容易受极端值影响。
- 中位数把排序后的数据一分为二，对极端值更稳健。
- 分位数描述有多少比例的数据不超过某个位置。

维修时长常有长尾，只报均值会隐藏大量快速工单和少量超长工单。通常同时报告中位数与高分位数。

## 29. 方差和标准差描述离散程度

总体方差可理解为每个值与均值差的平方，再取平均。标准差是方差开平方，恢复原单位。

平方让正负偏差不会抵消，也让大偏差权重更高。样本方差和总体方差分母不同，报告时应知道使用哪个定义。

## 30. 期望是长期加权平均概念

离散随机变量的期望：

```text
E[X] = Σₓ x · P(X=x)
```

期望不一定是某次实际可能出现的值。它适合比较长期成本，如误报成本与漏报成本的加权决策。

## 31. 抽样方式决定统计结论能否推广

只采集“成功关闭的工单”会有幸存者偏差；只采集白班会漏掉夜班分布；传感器故障可能造成非随机缺失。

随机种子只能复现一次抽样，不能修复选择偏差、测量偏差和未来信息泄漏。

## 32. 相关不代表因果

两个量一起变化，可能是 A 导致 B、B 导致 A、第三个变量同时影响两者，或数据选择造成假象。

预测模型可以利用相关性，但不能因此宣称某特征是原因。因果结论通常需要更强设计，如随机实验、自然实验或严格因果假设。

## 33. 导数表示函数在某点附近的变化速度

平均变化率是有限区间的 `Δy/Δx`；导数考虑区间趋近于零时的局部变化率。

在图像上，导数是该点切线斜率。导数为零可能是最小值、最大值、鞍点或平坦区域，不能单独证明达到全局最优。

## 34. 偏导数一次只考察一个输入方向

多元函数 `L(w₁, w₂, ...)` 对每个参数都有偏导数。求某个偏导时把其他变量暂时视为常量，而不是设为零。

把所有偏导按参数顺序排成向量，就得到梯度。

## 35. 梯度指出局部增长最快的方向

梯度 `∇L` 的每个分量说明对应参数轻微增加时，损失怎样变化。负梯度方向是局部下降最快方向，因此基本梯度下降写作：

```text
w_new = w_old - learning_rate × ∇L(w_old)
```

坐标缩放会影响“最快”的几何意义，这也是特征缩放和优化器设计的重要背景。

## 36. 链式法则连接复合函数的变化

若 `y=f(u)` 且 `u=g(x)`：

```text
dy/dx = (dy/du) × (du/dx)
```

神经网络由许多层复合，反向传播就是从损失向前面的参数系统地应用链式法则。一个值沿多条路径影响结果时，各路径贡献需要相加。

## 37. 学习率决定每次更新走多远

学习率太小，训练进展慢；太大，可能跨过低点、震荡或发散。损失并不保证每一步都严格下降，但在简单可控实验中，持续上升通常是符号、尺度或学习率问题。

不能只靠“训练更久”修复错误梯度。

## 38. 有限差分可以独立检查梯度

对参数 `wᵢ` 做很小正负扰动：

```text
近似梯度 = [L(wᵢ+h) - L(wᵢ-h)] / (2h)
```

把它与解析/自动梯度比较，可发现链式法则漏项和符号错误。`h` 太大会近似粗糙，太小会受浮点舍入影响。

有限差分计算贵，适合小模型和少量参数的检查，不用于完整训练。

## 39. 数学实现要有三层核对

```text
手算小样本：知道精确或近似结果
形状与单位：每一步输入输出都合理
性质检查：概率和为 1、距离非负、损失有限等
```

只对照同一份代码生成的 expected，可能让实现和核对一起犯错。

## 40. 图像是观察工具，不是最终证明

读图先看标题、轴名、单位、范围、是否对数轴、样本量和缺失处理。截断纵轴、双纵轴和平滑曲线都可能放大或隐藏变化。

模型曲线还应附数据划分、指标定义、随机性和置信范围。

## 41. 这一阶段应形成的整体地图

```text
单位与代数：把业务关系写成可核对公式
函数与图像：观察输入怎样影响输出
线性代数：用 shape 组织批量加权计算
概率统计：描述不确定性、分布和抽样
微积分：用梯度说明参数怎样影响损失
```

必须掌握：单位和分母是指标的一部分；形状必须带轴语义；逐元素乘法不等于点积；广播合法也可能错；条件概率不能反着读；均值会被长尾影响；相关不是因果；梯度是局部信息；反向传播是链式法则的组织化执行。

更严格的证明、统计推断和高阶优化可在项目需要时深入；当前重点是能解释公式、手算小例子、检查 shape/单位，并识别结论边界。
