# 学习讲义库

这里保存面向长期复习的完整主题讲义。它们按技术和知识主题归档，不依赖聊天记录，也不只用 Week 编号命名。

## 使用方式

1. 每个学习周开始时，先阅读对应讲义；
2. 连续从头读到尾，中途不需要回复“继续”；
3. 有疑问时按标题或小节提问；
4. 没有疑问时结束概念阶段；
5. 再进入一个连贯项目，把本章概念放入真实数据流；
6. 讲义阅读完成不自动等于整周通过，周通过仍以项目和比例化验证为证据。

完整路线、生成状态和权威周次入口见[学习讲义覆盖索引](./COVERAGE.md)。

## 命名规则

文件名以长期回看时容易识别为优先：

```text
study-guides/<技术分类>/<顺序号>-<技术名>-<中文知识主题>.md
```

顺序号用于排序，技术名保留常见写法，后面直接写本章主要知识点：

```text
02-Java-String、数组与控制流.md
→ Java：String、数组与控制流

03-Java-类、对象与封装.md
→ Java：类、对象与封装

04-Java-继承、接口与多态.md
→ Java 面向对象：继承、接口与多态

39-PyTorch-张量、模型与训练流程.md
→ PyTorch：张量、模型与训练流程
```

讲义正文从第 1 节开始连续编号，先用通俗语言解释概念，再补充会在 IDE、文档和面试中遇到的专业名称。课程管理信息、测试要求和进度证据不机械复制进讲义正文。
