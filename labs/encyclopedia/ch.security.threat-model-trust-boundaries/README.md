# FactoryCare 威胁模型可重放实验

实验读取固定 TSV 教学模型，不访问网络。基线包含浏览器、Java 公共适配器、工单服务、PostgreSQL、第三方通知，模型中的每个节点都有信任域，每条流有数据分类，跨域流有边界。

```bash
./verify.sh
```

脚本先验证基线，再从 `fixtures/faults.tsv` 注入四个故障：

- 删除管理员主体，模拟“只列技术漏洞、遗漏内部/管理路径”；
- 删除互联网到应用的边界；
- 添加没有对应威胁的 WAF 控制；
- 删除越权威胁的验证证据。

每个故障必须非零退出，并报告第一处可信结构偏差。先预测四个 marker，再运行。修复练习时必须重跑同一验证器，不能换一个更简单的输入。

## 安全与适用边界

所有名称、租户和事件都是虚构的；没有密码、Token、主机或账号。TSV schema 只用于教学引用完整性，不评估真实控制强度，不证明威胁清单完整，也不替代 FactoryCare 权威威胁模型。
