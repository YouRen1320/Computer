## 已验证

- 能识别 `int` 变量、赋值和算术表达式，并在运行前预测输出；
- 实测 `5 / 2` 先按整数除法得到 `2`，再赋给 `double` 得到 `2.0`；`5.0 / 2` 得到 `2.5`；
- 实测字符串拼接从左到右：`"total=" + 1 + 2` 得到 `total=12`，加括号后得到 `total=3`；
- 在 `ScopeDemo` 中真实复现块内变量越界访问的 `找不到符号` 编译错误；删除错误访问后输出 `3`、`13`，退出码为 `0`；
- 实测两个较大 `int` 相乘发生静默溢出，结果为 `-294967296`；乘法完成后再赋给 `long` 仍为错误值；参与运算前转换为 `long` 得到 `4000000000`；
- `Math.multiplyExact(int, int)` 能通过编译，溢出发生在运行阶段，异常为 `ArithmeticException`，实测退出码为 `1`；改为 `long` 重载后输出 `before`、`4000000000`、`after`，退出码为 `0`；
- 能解释基本类型复制值，以及引用变量复制引用值：`secondLabel = firstLabel` 后两个变量都引用字符串 `"ready"`，随后把 `secondLabel` 改为引用 `"done"` 不会修改 `firstLabel`。

## 纠正过的误区

- 赋值目标是 `double` 不会反过来改变右侧 `5 / 2` 的整数运算规则；
- 源码编译失败时程序没有启动，因此不会先输出错误行之前的内容；
- 普通 `int` 溢出不会自动从最小值重新精确计算，而是只保留低 32 位，表面表现为回绕；
- `Math.multiplyExact` 的溢出不是编译失败，而是运行时异常；本次实际退出码为 `1`，不是 `-1`；
- Java 的引用变量保存的是引用值；给其中一个变量重新赋值，不等于修改另一个变量或原字符串对象。
