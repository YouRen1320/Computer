# 第 35 周：Flutter真实API、离线同步、设备能力与构建

## 本周定位

本周让技师App进入真实业务。重点不是页面数量，而是移动端独有问题：认证恢复、弱网、离线变更、重复同步、版本冲突、拍照扫码、权限和真机构建。

## 前置条件

- Week 34架构和测试通过；
- Java `/api/v1`、OpenAPI、幂等键和版本字段可用；
- 已选择Android或iOS为主验证端；
- 有至少一台可用Android或iOS真机；模拟器可用于开发，但不能替代G5真机验收。

## 本周目标

- 从OpenAPI生成或约束Dart API客户端；
- 安全处理认证、刷新、超时、错误和日志；
- 设计离线读缓存与离线写队列；
- 用幂等键和版本处理重复/冲突；
- 离线记录检查项、工时、备件和解决结果，并安全同步；
- 完成扫码、拍照、压缩、上传和权限；
- 建立单元、Widget、集成与构建验证。

## 必须理解的概念

- REST客户端、拦截器、超时、取消、有限重试和错误映射；
- access/refresh token或OIDC会话、secure storage、登出清理；
- OpenAPI生成客户端的收益、生成物边界和契约漂移；
- cache-first、network-first、stale-while-revalidate与offline-first；
- SQLite/Drift表、迁移、事务和本地事实边界；
- mutation queue、idempotency key、retry count、dead letter；
- 乐观版本、冲突检测、last-write-wins风险和人工解决；
- 网络状态只能作为提示，真实请求结果才是证据；
- 相机、相册、二维码、文件、MIME、EXIF和权限生命周期；
- 预签名上传与经Java授权上传的取舍；
- 推送token、前后台消息、深链和失效概念；
- flavor、环境配置、签名、混淆、崩溃日志和发布通道；
- 单元、Widget、Integration Test职责。

## 时间与任务（15—18小时）

下方120分钟无AI训练计入任务3的离线同步与冲突实现，不在总时长之外重复增加。

### 任务1：API与认证（3小时）

- 锁定OpenAPI版本并生成Dart类型/客户端，或建立严格手写客户端；
- 实现超时、取消、错误码和traceId映射；
- 实现认证恢复与单次刷新并发控制；
- 验证401、403、网络中断和服务端校验错误；
- 日志不得输出token和敏感表单。

### 任务2：本地数据模型（3小时）

- 为工单摘要、详情、检查项、工时、备件使用、解决草稿和待同步命令设计本地表；
- 明确哪些数据可缓存、何时过期、谁是权威；
- 写一次本地迁移；
- Repository组合远端和本地数据；
- 用测试验证重启后状态恢复。

### 任务3：离线同步（4小时）

- 离线接单并更新检查项、工时、备件使用和解决草稿，全部写入mutation queue；
- 为每个命令生成稳定idempotency key；
- 恢复网络后按顺序同步，使用有限指数退避；
- 区分可重试、不可重试和需要人工处理；
- 服务端版本冲突时展示差异或明确重新加载；
- 测试重复发送、App中途退出和部分成功。

### 任务4：扫码、拍照与上传（3小时）

- 扫码读取asset标识并向Java查询授权资源；
- 请求相机/相册权限，并处理拒绝和永久拒绝；
- 拍照后压缩、纠正方向或保留必要元数据；
- 校验大小、类型和数量；
- 显示上传进度、失败重试和取消；
- 服务端验证对象归属，客户端URL不能决定权限。

### 任务5：测试与构建（2—3小时）

- Repository同步单测；
- 离线队列重复/冲突测试；
- 一个拍照/上传Widget行为测试；
- 一条从待办、接单、检查、工时/备件到提交解决的集成测试和可重复真机脚本；
- 至少构建一个debug/release候选包，记录签名和环境配置差异。

### 任务6：复盘和面试（1小时）

- 绘制离线同步时序图；
- 准备回答“为什么不能只在网络恢复时重新POST所有数据”；
- 更新作品集已验证端和未验证端。

## FactoryCare项目增量

- 技师登录/恢复；
- 真实待办、详情、接单、检查项、工时、备件使用和解决提交；
- 离线检查项和同步队列；
- 扫码识别设备、拍照和附件上传；
- 版本冲突和错误恢复；
- 主目标平台可构建候选包。

## AI协作边界

可以让AI生成OpenAPI客户端配置、序列化样板和测试数据，但必须人工检查：token存储、重试幂等、冲突逻辑、数据库迁移、权限和日志。不得让AI把“网络可达”当作数据已同步，也不得静默丢弃失败命令。

## 无AI训练（120分钟）

为已有同步队列增加“服务器返回409版本冲突”处理：停止该实体后续命令、保存服务端摘要、展示人工选择，并确保其他实体继续同步。补单元测试。

## 求职动作（恢复求职后启用）

- 录制不超过2分钟的真机弱网演示；
- 简历只写实际验证的平台；
- 模拟面试：离线缓存与离线优先区别、幂等与去重区别、推送与WebSocket区别。

- [ ] 扫码拍照上传链路；
- [ ] 工时、备件和解决提交的离线/同步证据；
- [ ] 单元/Widget/集成证据；
- [ ] 至少一个平台构建与一台真机主链路记录；
- [ ] 离线时序图、真机记录和周复盘。

## 验收标准

- 断网不会丢失已确认保存的本地记录；
- 重复同步不会重复创建/扣减；
- 冲突不会静默覆盖；
- token不出现在普通日志和非安全存储；
- 权限拒绝、上传失败和App重启均有可解释状态；
- 一台真实设备可完成登录、接单、扫码、检查、工时/备件、拍照和解决提交；
- `flutter analyze`、测试和目标构建通过。

## 本周明确不做

- 完整后台定位、蓝牙和原生插件；
- 同时发布App Store与全部安卓商店；
- 复杂端到端加密聊天；
- 把本地数据库当成跨设备权威；
- 无限重试和自动解决所有冲突。
