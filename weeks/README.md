## 每周执行入口

1. 复制[周复盘模板](../templates/weekly-review.md)；
2. 先完成本周基线或前置检查；
3. 把重大项目任务写入[项目任务模板](../templates/project-task.md)；
4. 按本周交付物执行；
5. 完成无AI训练；
6. 评分并决定通过、补考或延长；
7. Week 01—18从求职/复盘时段完成当周45—60分钟算法主题；Week 19—36每周复测1道历史错题或做一次口述；
8. 更新[岗位跟踪](../templates/job-tracker.csv)和面试复盘。
