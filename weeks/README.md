## 每周固定动作

1. 运行学习教练的只读进度检查；
2. 只加载当前周和当前任务所需材料；
3. 先预测再运行，保存成功与失败证据；
4. 完成一个 FactoryCare 小切片和一项关闭 AI 的小改动；
5. 运行构建、测试、类型检查或数据库验证；
6. 写一条误解、一条可复用规则和下一次复习日期；
7. 达到验收后才更新 [PROGRESS.md](../PROGRESS.md)。

算法与计算机基础从 Week 01—21 每周安排 45—60 分钟，之后按错题和面试需要保持；它不能替代主线项目，也不能完全推迟到求职前。
