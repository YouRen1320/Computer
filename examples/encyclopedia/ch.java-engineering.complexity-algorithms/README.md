# 示例：线性/二分操作计数与 Map 索引

示例在 128 个已排序工单 ID 上同时运行计数版线性搜索和二分搜索，比较命中/缺失结果与比较次数；另外输出 n=10²/10⁴/10⁶ 的增长模型、16 项嵌套去重的比较对，以及一次建立 HashMap 后的等价查询。所有 oracle 使用操作数，不使用墙钟。

运行前预测：

1. 128 项缺失线性搜索比较多少次；二分最多经过多少次减半；
2. 第 73 项命中时两种算法各比较多少次；
3. 16 个全唯一元素做“与此前所有元素比较”产生多少对；
4. n 扩大 10000 倍时，线性与对数模型分别如何变化；
5. 未排序 `[9,1,7,3]` 上二分查 9 是否有合法保证。

```bash
cd examples/encyclopedia/ch.java-engineering.complexity-algorithms
./verify.sh
```

验证器要求 Java 25、零警告、正例精确输出 10 行；未排序二分程序必须非零退出并出现 `UNSORTED_PRECONDITION`。计数趋势不是生产耗时证明。
