# 结构化日志与 JVM 证据摘要示例

这个纯 JDK 25 示例不连接日志平台，也不附着其他 JVM。它使用固定时间、固定 correlation ID、固定异常栈、固定线程 dump 与固定 GC 日志，演示：

- 稳定事件名和有序结构化字段；
- authorization 等敏感键统一输出 `[REDACTED]`；
- CR/LF 被转义，不能伪造新日志行；
- 异常保留类型、cause 和栈存在性；
- 从线程快照找到 BLOCKED 数量及锁拥有者；
- 汇总 GC 事件、暂停和回收量，同时不声称已证明根因。

先写出你预测的五行输出，再运行：

```bash
./verify.sh
```

验证器还运行“非法 correlation ID”和“明文 secret”两个预期失败。所有输入离线固定，结果不依赖 PID、线程调度、当前时间或本机 GC。

## 边界

夹具解析器只认识仓库中的教学格式，不是通用 JDK dump/GC parser。通过结果不代表任何真实 JVM 已采样，也不证明日志后端、文件轮转、采集器、JFR 或告警配置正确。
