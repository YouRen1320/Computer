# Week 06 面试题与追问

## 使用方式

每次随机抽一题，先在 90 秒内回答“结论—机制—FactoryCare 证据—边界”，再用 60 秒处理追问。先保存自己的回答；完成一轮后才能查看[答案册的面试校准](./answers.md#面试校准)。本文件不提供答案锚点。

## 1. checked exception 和 unchecked exception 怎么选？

追问：

1. 为什么不让所有领域异常都 checked？
2. 把 IOException 包成 RuntimeException 有什么风险？
3. Spring 事务默认回滚规则会怎样影响后续设计？本周只说概念。

## 2. `catch Exception` 有什么问题？

追问：

1. 应用最外层能否捕获 Exception？
2. 日志后重新抛出是否一定正确？
3. 为什么返回空列表可能比抛异常更危险？

## 3. `finally` 一定执行吗？

追问：

1. try-with-resources 与 finally 手工 close 的差别？
2. close 也失败怎么办？
3. 多个资源的关闭顺序是什么？

## 4. try-with-resources 的工作机制是什么？

追问：

1. 资源在 try 外创建会怎样？
2. 为什么不能只看异常 message？
3. 数据库连接以后也适用吗？

## 5. 字节流与字符流如何选择？

追问：

1. 图片能用 Reader 吗？
2. `Files.readString` 适合多大文件？
3. UTF-8 中文往返怎么测试？

## 6. 如何防止路径穿越？

追问：

1. 只过滤字符串中的 `../` 为什么不够？
2. `normalize` 是否会访问文件系统？
3. `toRealPath` 对不存在的导出目标怎么办？

## 7. 什么叫原子写文件？

追问：

1. `ATOMIC_MOVE` 在所有平台都支持吗？
2. 指定 `ATOMIC_MOVE` 时，`REPLACE_EXISTING` 是否仍提供保证？
3. 临时文件放系统 tmp 目录有什么风险？
4. move 成功是否等于数据已经物理落盘？

## 8. `Instant` 和 `LocalDateTime` 的区别？

追问：

1. 工单 `createdAt` 用哪个？
2. 用户预约“明天上午 9 点”用哪个？

## 9. `ZoneId` 与 `ZoneOffset` 有什么不同？

追问：

1. Asia/Shanghai 是否会改变 Instant？

## 10. `Duration` 与 `Period` 怎么选？

追问：

## 提交与校准

保存 20 题回答、实际代码/测试引用和“未验证”标记后，再打开[面试校准](./answers.md#面试校准)。若提前查看，本轮只能算练习，不能作为无 AI 口述成绩。

## 模拟面试评分

| 维度 | 5 分表现 |
| --- | --- |
| 准确性 | 类型、异常和时间语义无关键错误 |
| 深度 | 能说机制、失败与限制，不只背 API |
| 项目证据 | 每题至少能连接一个真实测试或明确未验证 |
| 表达 | 先结论，再例子，再边界 |
| 诚实 | 明确个人实验与生产经验差别 |

总分低于 18/25 时，挑三个薄弱题重新做实验后再录一次。
