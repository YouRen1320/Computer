# Week 01 面试训练

一次只问一题。先让学习者回答，再追问；答案锚点只在 [answers.md](./answers.md) 的“面试校准”中读取。

## 程序与 I/O

1. 经典 `public static void main(String[] args)` 每一部分做什么？
2. package、import 和依赖安装有什么区别？
3. `System.out`、`System.err`、方法参数和 return 分别属于哪一层？
4. 为什么不建议业务方法直接 new Scanner？

## 类型与运算

5. Java 八种基本类型有哪些？项目中常用哪些？
6. `5 / 2` 是什么？为什么？
7. int 溢出会发生什么？怎样让关键计算明确失败？
8. widening 与 narrowing 有什么风险？
9. 为什么金额不直接用 double？

## 方法与测试

10. Java 参数是按值还是按引用传递？引用对象为何仍会被修改？
11. static 方法解决什么，本周为什么可以用它？
12. package-private 方法为何能被同 package 测试调用？
13. 编译错误、运行时异常和断言失败如何从 Maven 日志区分？
14. `BUILD SUCCESS` 是否等于功能正确？
15. expected 值应从哪里来？

## 项目追问

16. 展示金额计算器的数据流和失败路径。
17. 说一次你定位过的真实错误，或验证过的高风险失败路径。
18. AI 做了什么、你定义了什么预期、怎样审查并验证？
19. 如果把“单价 × 数量”迁移成“配件费 + 时薪 × 工时”，哪些结构可以复用，哪些规则必须改变？

## 自评分

- 0：只知道名词；
- 1：能给定义但无代码/日志；
- 2：能结合本周实现和边界；
- 3：能比较取舍、定位故障并修改需求。
