# Week 01 深度教学包：Java 语法、类型、控制流与 JUnit

本周从 TypeScript/Vue 开发者的已知经验出发，建立 Java 的最小可执行心智模型。目标不是背完语法，而是能把一组 FactoryCare 优先级规则写成明确方法、用测试证明边界，并在关闭 AI 后修改规则和定位故障。

对应[原 Week 01 计划](../../weeks/week-01.md)。本周只使用 Java 25、最小 Maven 工程和 JUnit，不引入 Spring、数据库、JSON、集合、Stream 或领域建模。

## 推荐学习循环

每一小节采用相同闭环：

1. 先预测代码能否编译以及输出；
2. 运行并保存证据；
3. 主动制造一个编译错误、运行时异常或测试失败；
4. 只根据错误位置和最小上下文定位；
5. 修复后补回归测试；
6. 用自己的话解释 TS 类比在哪里成立、在哪里失效。

## 本周 FactoryCare 结果

只实现一个纯函数式规则对象：`WorkOrderPriorityCalculator`。输入为严重度、停机、安全风险和受影响设备数量，输出暂时为明确字符串 `LOW`、`MEDIUM`、`HIGH`、`CRITICAL`。这些是优先级值，不是工单状态。

Week 02 才把结果重构为 enum/value object。本周不要创建 `WorkOrder` 实体，不要添加仓储、控制器或数据库。

## 通过标准

- 能解释源文件、字节码、JVM、编译错误、运行时异常、测试失败；
- 能解释八种基本类型、引用、`null`、`String` 不可变、数组固定长度；
- 正确陈述“Java 始终按值传递，对象参数复制的是引用值”；
- 优先级决策表没有遗漏或冲突，非法输入明确拒绝；
- JUnit 覆盖成功、边界和失败路径；
- 独立完成一项规则变更并恢复一个故意故障；
- 数组题能说出循环不变量、时间和空间复杂度。

按[每周 100 分标准](../../ASSESSMENTS.md)达到 75 分，且项目、测试、无 AI 均达到各自 60%，方可进入 Week 02。
