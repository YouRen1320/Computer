## 学习顺序

1. 先把一个完整类、经典 `main` 和测试作为整体示例运行起来；
2. 沿“命令行文本 → 解析 → 纯计算 → 输出”解释完整数据流；
3. 只对整数除法、溢出、参数边界等高价值点做少量预测；
4. 保留 package、class、main 和错误处理脚手架，补全或改变承载概念的部分；
5. 把金额计算模式迁移到一个相似但不相同的维修估价小程序；
6. 复用已有测试并运行代表性路径，不为完成清单重复造错。

## 通过标准

- 构建与测试证据真实；
- 能找到并解释经典 main、基础输入输出和纯计算方法的职责；
- 能解释基本/引用类型第一层差异、整数除法、转换和溢出；
- 能解释 `static` 在当前方法中的作用，不要求完整对象模型；
- 能从日志判断 compile、testCompile、runtime、assertion failure；
- 能在现有示例帮助下完成一个非同构的小迁移，并运行与声明相称的证据；
- 普通周结论只记“证据通过”或一个明确缺口，不做百分制考试。

## 非目标

- 不系统学习 String API、null 设计、数组和循环；
- 不学习对象构造、继承、集合或 Spring；
- 不把 Maven 命令背诵当 Java 能力。
