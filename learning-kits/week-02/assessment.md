# Week 02 无 AI 考核

## 规则

- 120 分钟；允许 JDK/JUnit 官方 API，不用 AI/答案册；
- 总分 ≥75，项目增量、测试与排错、无 AI 任务各 ≥60%；
- 提交代码、测试、命令、复杂度和复盘。

## 题目：技师当日工时规则

输入技师姓名和工时分钟数组，输出：规范化姓名、总有效分钟、有效记录数、最长单项、是否超出 480 分钟、首个超长单项（>240）索引。

契约：姓名 null/blank 失败；数组 null 失败、空数组返回零统计；单项 0 合法，负值/大于 720 非法并失败；不修改输入。

## A. 概念解释（20 分）

- String `==/equals`；null/empty/blank；
- 数组索引和引用共享；
- for/增强 for/while 选择；
- break/continue/return；
- 单次扫描复杂度与循环不变量。

## B. 最小实验（15 分）

预测并运行 String 身份/内容、数组赋值共享、`i <= length`、过早 return 四个小实验。

## C. 项目增量（25 分）

方法拆分清晰，输入验证、统计和输出边界明确；使用一次扫描，不靠集合/Stream；不修改输入数组。

## D. 测试与排错（20 分）

覆盖正常、空、0、480/481、240/241、负值、721、null/blank、数组 null；故意引入过早 return，用测试/调试器定位并恢复。

## E. 无 AI 任务（15 分）

最后 20 分钟增加“只统计前 `limit` 条记录”，limit 0/等于长度/大于长度/负数契约先写测试；不得复制整个方法。

## F. 复盘与求职（5 分）

当前求职暂停：记录误解、可复用循环规则、未验证点和复习日期，不虚构求职动作。
