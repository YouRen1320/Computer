# Week 02 面试训练

## 使用方式

每题先用 60—90 秒回答；至少一半回答必须引用 `EquipmentCode`、`WorkOrder` 或防御性复制实验。保存整轮回答后，再查看[答案册的面试校准](./answers.md#面试校准)。

## 基础层

### 1. 类和对象有什么区别？

追问：class 是否等于数据库表？

### 2. 什么是封装？

追问：private 字段加 getter/setter 够吗？

### 3. `static` 与实例成员有何区别？

追问：为什么不把当前工单放 static 字段？

### 4. `final` 是否等于不可变？

追问：final 数组怎样仍被修改？

## 类型选择层

### 5. class、record、enum、interface 怎么选？

追问：为什么 WorkOrder 不做 record？

### 6. record 自动提供什么？没有提供什么？

追问：record 组件是数组会怎样影响不可变和相等？

### 7. 为什么 enum 不用 `ordinal()` 存数据库？

追问：`name()` 能否直接作为 API 值？

### 8. interface 与抽象类有何区别？

追问：是否每个 Service 都要接口？

## 领域建模层

### 9. Entity 与 Value Object 如何区分？

追问：EquipmentCode 为什么是 Value Object？

### 10. DTO 与 Value Object 有何区别？

追问：请求 DTO 校验通过后为何领域仍需校验？

### 11. 什么是不变量？

追问：举出 WorkOrder 三个当前已经保护的不变量，以及一个尚未实现的不变量。

### 12. 为什么组合优先于继承？

追问：继承何时合理？

### 13. 为什么不用 BaseEntity 统一 id？

追问：少写几行代码是否足以证明抽象有价值？

## 项目边界层

### 14. 为什么 Week 02 不实现完整状态机？

追问：现在怎样防止任意状态？

### 15. 为什么不为 Jackson/MyBatis 先加无参构造和 setter？

追问：以后框架确实需要时怎么办？

### 16. TypeScript 迁移到 Java 建模最危险的类比是什么？

追问：给一个真实故障或测试证据；尚未发生时明确说明。

## 压力题

面试官：“这么多小类型是不是过度设计？”请说明类型的成本、选择标准，并给出一个保留和一个主动删除的类型例子。

## 提交与校准

保存回答、构造失败测试和未验证项后，再打开[面试校准](./answers.md#面试校准)。提前查看时，本轮只能作为练习。

## 自评分

每题 0—3 分，共 48。36 分以上，且第 5、9、11、14 题至少 2 分为通过。只背 DDD 定义但无法展示构造失败测试，相关题最高 1 分。
