# Week 02 面试训练

一次只问一题，回答后再追问。

## String 与 null

1. 为什么 String 内容不能默认用 `==` 比？
2. null、空字符串、空白字符串有什么业务差异？
3. String 不可变意味着什么？循环拼接为什么可能用 StringBuilder？
4. `split(".")` 为什么可能不是按点切分？

## 数组与循环

5. Java 数组与 JS Array 的核心差异是什么？
6. 为什么最后一个合法索引是 length-1？
7. 数组赋值给另一个变量后修改会怎样？
8. for、增强 for、while、do-while 分别适合什么？
9. break、continue、return 的范围区别？
10. 什么是 off-by-one 和循环不变量？

## 条件与方法

11. 复杂优先级规则为什么先写决策表？
12. switch expression 适合什么，不适合什么？
13. 早返回如何提高可读性，又会制造什么风险？
14. 怎样把解析、计算和输出拆方法？

## 项目与排错

15. 一次数组扫描为什么是 O(n)？
16. 展示一次调试器找到过早 return 的证据。
17. 如何测试临界值 23/24 小时？
18. AI 生成循环后你会审查哪些点？

## 自评分

- 0：只会语法；
- 1：能定义；
- 2：能结合代码/测试；
- 3：能解释契约、复杂度、故障和修改。
