# Week 00 深度教学包：环境、基线与可回滚起点

本教学包把[原 Week 00 计划](../../weeks/week-00.md)拆成可以逐项执行、留存证据和独立验收的准备周。它不要求把未来 36 周的软件一次装完，也不生成 FactoryCare 的业务脚手架。

当前执行决定（2026-07-15）：用户暂停求职，因此岗位材料保留已有样本，简历任务延期；G0按真实环境、构建、测试、故障恢复、能力基线、Git和FactoryCare准备材料判断技术准入。已有等价实操证据时，不重复进行工具链背诵考试。详见[当前执行方案](../../STUDY_EXECUTION.md)。

## 本周完成定义

完成本周时，你应当能够证明：

- 终端、Maven 和 IDE 使用同一个 JDK 25 LTS；
- Maven 为 3.9.16，且能运行一个非 Spring 的 JUnit 烟雾测试；
- Node、pnpm、Python、uv、Flutter 和 Docker 的现状、目标版本、安装触发周次均已记录；
- 能独立解释并排查 `PATH`、`JAVA_HOME`、`java`、`javac` 和 `mvn` 不一致；
- 有五项能力基线；恢复求职前再要求40个可追溯岗位样本与两版事实型简历处于可用状态；
- 工作区有可回滚 Git 起点，且没有提交密钥或机器隐私；
- FactoryCare 只有一页业务说明和首份 ADR，没有提前创建 Spring、数据库或前端工程。

## 推荐执行顺序

```text
先记录现状
  → 再选择唯一主版本来源
  → 写回滚方案
  → 小步修改
  → 新终端复验
  → IDE/Maven 交叉验证
  → 制造受控故障并恢复
  → 做基线与岗位样本
  → 无 AI 考核
```

每次修改 shell 配置前都先保存原始内容和恢复命令。禁止为了练习故意删除 JDK、覆盖系统文件或执行不理解的远程脚本。

## 阶段门 G0

按[ASSESSMENTS.md 的 G0](../../ASSESSMENTS.md)评估。最低门槛不是“所有命令都能找到”，而是：

- `java -version`、`javac -version`、`mvn -v` 的 JDK 均为 25；
- 最小测试可从命令行运行；
- 未来依赖有按需安装计划；
- 40 个岗位样本和两版简历不虚构能力；
- 能口述主线、非目标和 AI 边界。

未通过时，只补直接阻塞 Week 01 的问题。Node、Flutter 或 Python 暂未升级，不阻塞进入 Week 01。

## 本周不做

- 不安装 PostgreSQL、Redis、MQ、Kubernetes、LangChain 或本地模型；
- 不创建 Spring Boot、Vue、uni-app、Flutter 或 Python 服务；
- 不清理用户已有工具，不并用多个版本管理器；
- 不优化终端主题和无关插件；
- 不把计划学习内容写成已经掌握或商业项目经验。

完成并评分后进入[Week 01 教学包](../week-01/README.md)。
