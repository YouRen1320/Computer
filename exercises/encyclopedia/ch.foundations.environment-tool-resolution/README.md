# 练习：环境变量、PATH 与工具版本解析

先独立保存答案，再看私有解析。题目只允许使用占位符和临时子进程，不修改真实配置。

## A. 继承图

父 Shell 导出 `MODE=parent`，对子命令临时设 `MODE=child`，子命令再启动孙进程。写出父运行前、子、孙、子结束后父的值和理由。说明普通未导出变量的差异。

## B. 作用范围

比较单命令前置赋值、当前 Shell `export`、写入启动文件。分别说明持续时间、影响对象、回滚、验证入口与风险。为什么“新终端才生效”不是因果解释？

## C. PATH 预测

A/B 目录都有 `demo-tool`。对 PATH=A:B 和 PATH=B:A 写出 `type -a` 顺序、`command -v`、裸命令版本和绝对 A 入口版本。若 PATH 没有 A/B，预期失败在哪一阶段？

## D. JAVA_HOME 冲突

已知 PATH 首个 `java` 为 JDK 25、JAVA_HOME 为 JDK 21、Maven 启动器读取 JAVA_HOME。解释 `java -version` 与 `mvn -v` 的不同，不使用“全局优先级”含糊表述。给出会话内最小修复和复跑证据。

## E. IDE 分叉

IDE 项目 SDK=25，终端裸 Java=21。列出两个父进程/入口的证据，说明为什么任一侧成功都不能证明另一侧。不得建议直接卸载 21。

## F. 安全审查

AI 建议把 `.` 放到 PATH 最前、执行完整 `env` 后上传、把一段远程脚本追加到 `.zshrc`。逐项指出命令劫持、秘密泄露、持久启动代码和回滚风险，给出只读安全观察替代方案。

## G. 需求变更

项目主线从 A 切到 B，但必须保留 A 供旧项目使用。设计明确项目入口、PATH/JAVA_HOME 合同、版本证据和回滚，不以删除 A 解决并存。

## H. 无 AI

关闭 AI，限时 50 分钟完成 A—F。用 120 秒解释“环境由父传子、PATH 从左到右选择、工具启动器还可能消费 JAVA_HOME”，保留一次错误预测并分类。
