# 练习：学习证据、掌握标准与间隔复习

先保存自己的回答，再查看隔离解析。

## A. 预测与分类

把下列记录分类为“过程痕迹、产物、可重放证据、延迟检索”，并写出每项不能单独证明什么：

1. 看完四小时课程；
2. 项目目录里有十个源码文件；
3. 固定输入下两个断言通过，日志记录测试数量、期望与实际；
4. 七天后不看答案完成一个阈值需求变更并修复边界故障。

## B. 构建

把“我会绝对路径和相对路径”改写成可证伪 claim，必须包含起点、目标、两个路径表示、一个错误起点反例和未验证平台。

## C. 故障

修复实验中的 `faulty-ledger.yml`。不能只把 `mastered` 改为 `supported`，必须补全 explain/build/diagnose、固定输入、预测、观察、首证据、修复复跑、边界和复习。

## D. 需求变更

原验收只有正常数量。现在增加数量为 0、恰好等于阈值和非法负数。先更新证据合同，再更新实现或测试，解释为什么不能先改代码再猜预期。

## E. 无 AI

关闭 AI，限时 30 分钟，从空白文件建立一份有效账本。允许查看正文速查表，不运行示例复制答案。最后做 120 秒复述：为什么文件存在、构建成功和 AI 自述都不能单独证明掌握？
