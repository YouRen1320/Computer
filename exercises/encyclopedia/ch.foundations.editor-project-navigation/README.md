# 练习：编辑器、IDE、项目导航与源码定位

先保存自己的答案，再查看私有解析。除配套临时样例外，不要运行陌生项目任务，不要修改 `target/`、`build/`、`dist/`、依赖缓存或真实 IDE 私有配置。

## A. 项目根判断

给定仓库根包含 `README.md`，`backend/` 内含 `pom.xml`，`frontend/` 内含 `package.json`。分别说明做全仓搜索、启动后端、启动前端时应打开或选择什么范围；指出“根”为何可能随问题粒度变化，但仓库根与模块根不能混写。

## B. 路径角色分类

将 `src/main`、`src/test`、`resources`、`target/classes`、`target/generated-sources`、External Libraries、`.idea/workspace.xml` 分为规范输入、测试输入、派生输出、依赖视图和个人状态。每项写“通常是否修改”与必须查询的项目合同。

## C. 三种搜索

为以下目标选择文件搜索、全文搜索或符号搜索，并说明退路：已知 `WorkOrderService.java`；只知道错误文字 `invalid status`；已知方法 `assignTo`；语言服务尚未加载；同名类跨两个模块。

## D. 定义与引用

画出“测试调用→接口声明→实现候选→引用列表→返回原错误”的导航链。说明静态定义/引用为什么不能单独证明运行时调用了哪个实现。

## E. Problems 诊断

Problems 指向未保存缓冲区第 20 行，终端 Maven 构建成功；另一轮 IDE 无红线，但 `mvn test` 在 `testCompile` 失败。分别写生产者、输入状态、第一条核对动作和不能下的结论。

## F. 运行配置

给一份最小运行配置写出入口、工作目录、程序参数、运行时参数、环境、JDK/模块。解释“运行当前文件”为什么可能绕过 Maven 项目真实依赖。

## G. 生成物故障

AI 修改了 `target/generated-sources` 中返回值，页面暂时正常，`mvn clean` 后恢复错误。写出第一处可信证据、规范修复位置的寻找方法、验证步骤和不得执行的批量动作。

## H. 保存与编码

某中文配置文件在 IDE 中正常，提交 diff 却显示全文件变化。列出保存状态、编码、换行、格式化器和生成器的观察顺序。不得以“重新复制一份文件”作为首选修复。

## I. FactoryCare 需求变更

把状态标签方法从 `label` 改为 `formatStatus`。先用引用关系列出生产、测试、前端、文档与生成物候选；决定哪些本轮修改、哪些只观察、哪些交给生成任务，并给出最小回归预言。

## J. 安全审查

AI 建议安装未知导航扩展、信任陌生 workspace、运行项目内 `setup.sh` 并把整个环境贴进日志。指出执行、供应链、秘密和隐私风险，设计只读检查与最小披露方案。

## K. 无 AI

限时 50 分钟独立完成 A—H，并在任一 IDE 现场完成一次测试引用到生产定义再返回。120 秒复述项目根、搜索范围、语义索引、生成物、诊断生产者与运行配置的关系。
