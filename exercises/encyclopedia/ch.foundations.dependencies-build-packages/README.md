# 练习：依赖、包管理、构建生命周期与可重复性

先独立作答并保存预测，再查看私有解析。

## A. 依赖图

项目直接依赖 A，A 依赖 B，B 依赖 C。哪些是直接依赖，哪些是传递依赖？只在根项目删除 B 的声明为何不一定移除 B？

## B. 约束与锁

解释“允许 1.x”和“锁定 1.0.3”的不同职责。仓库新增 1.0.4 后，哪些输入不变仍不足以保证解析结果不变？

## C. 缓存

热缓存构建成功、空缓存失败，至少能推出什么？不能推出什么？写出最小诊断顺序。

## D. 生命周期

给定日志：clean、validate、compile 通过，test 失败，旧的 package 文件仍留在目录。为什么不能声称本次已打包？如何修正阶段与产物证据？

## E. 工具与环境

终端执行 `fc-build --version` 是 1.0，CI 是 0.8。列出 PATH、绝对路径、wrapper、子进程环境和报告中应保存的证据。

## F. 可重复性

同一机器连续两次摘要相等能证明什么？为什么还不能证明第三方跨机器重建？列出时钟、路径、区域设置和未锁插件四类泄漏。

## G. 故障闭环

设计一次“未锁版本漂移”和一次“test 失败却保留旧包”的受控故障。写 expected、首个可信证据、恢复步骤和复跑条件。

## H. 无 AI

关闭 AI，限时 45 分钟完成 A—G，并运行公开实验。保留预测、输出和 120 秒复述，不修改全局包缓存或 shell 配置。
