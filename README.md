# FactoryCare 编程百科与 AI-First 全栈学习工作区

这个工作区服务于一个明确目标：借助 16 卷、255 章的权威百科教材和一条保留真实进度语义的 48 周执行计划，把已有的 Vue3、TypeScript、Nuxt、Flutter、Python 经历补成一套从语言基础到生产交付都能验证的 Java/Vue 全栈与 AI 应用开发能力。求职线当前暂停，可以在用户明确恢复后重新启用，不阻塞技术主线。

本路线不会因为使用 Codex/Claude 就跳过基础，也不会把“AI 生成后能运行”当成学会。Java、Web/JavaScript/TypeScript、Dart、Python 都按语言基础、运行模型、测试调试、框架和真实项目逐层推进；已有经验只影响练习速度，不删除必备知识。

## 已确认的技术路线

| 层次 | 主技术 | 职责 |
| --- | --- | --- |
| 企业 Web | HTML、CSS、JavaScript、TypeScript、Vue3、Vite | 管理、调度、知识库、报表 |
| SSR/官网 | Nuxt 4 | 产品门户、公开内容、SEO 和 SSR |
| 小程序 | uni-app（Vue3） | 扫码报修、进度、确认、评价 |
| 移动 App | Dart、Flutter | 现场技师、拍照扫码、离线工单和同步 |
| 核心后端 | Java 25 LTS、Spring Boot 4 | 权限、事务、资产、工单、SLA 和审计 |
| AI 服务 | Python 3.14、FastAPI | 文档处理、RAG、工具调用、受控 Agent 和评估 |
| 数据与工程 | PostgreSQL、pgvector、Redis、对象存储、Docker | 业务数据、检索、缓存、文件和部署 |

Java 是业务事实和写操作的中心；Python 只提供 AI 建议、草稿、检索证据和可重建派生数据。客户端只调用 Java 公共 API，不直接访问 Python、数据库或私有对象存储。

## 所有语言怎样“从头学”

每门主语言都覆盖同一组基础问题，但结合各自运行模型：

1. 程序怎样启动、源码怎样变成运行结果；
2. 输入输出、变量、类型、运算符和空值；
3. 条件、`for`、`while`、集合和函数；
4. 类、对象、封装、继承/组合、多态和泛型；
5. 异常、文件、时间、序列化和外部边界；
6. 异步/并发、资源生命周期和取消；
7. 单元测试、调试器、日志、构建和依赖；
8. 框架、架构、真实项目、故障和发布。

Vue 不会被当成完全陌生框架慢速重学，但 HTML/CSS/JS/TS 基线和 Vue 核心机制都必须通过代码与解释。Dart、Python 也不再塞进单周“复健”，而是各有独立语言基础周。

## 每周投入与证据

默认每周 15—18 小时，48 周预算约 720—864 小时；这是计划值，不写入实际进度。

- 2—3 小时：定向概念与官方文档；
- 2 小时：阅读和导航完整代码；
- 2—3 小时：最小实验、预测和故障注入；
- 5—6 小时：FactoryCare 小切片；
- 2—3 小时：测试、日志、排错和审查；
- 1—2 小时：关闭 AI 的独立改动、口述与复盘。

如果一周只能投入 8—10 小时，就延长当前周并删掉扩展阅读；不删测试、排错和独立改动。

## “学会”的最低定义

一个主题至少同时满足以下事实，才算达到可就业的使用/接管水平：

1. 能用自己的话说明责任、边界和失败方式；
2. 能在项目中找到输入、输出、状态、副作用和规则位置；
3. 能借助 AI 完成最小实现，并逐段审查而非盲收；
4. 能用测试、日志、构建或数据库证据验证结果；
5. 能不重写整个功能地修改一条需求；
6. 能定位并修复一个人为引入的真实故障；
7. 能区分“已经验证”与“AI 推测可能正确”。

只看教程、抄代码、背定义或看到 `BUILD SUCCESS` 都不等于功能正确。

## AI-First 执行闭环

1. 人先说明目标、约束、输入输出和验收标准。
2. AI 解释刚好需要的概念并比较方案。
3. 学习者先预测，再运行完整、可复现的最小代码。
4. AI 只生成已确认的小切片；学习者检查 diff 和关键规则。
5. 自动运行格式化、类型、测试、构建和集成验证。
6. 主动制造一次编译、测试、运行时或集成故障并恢复。
7. 关闭 AI 后完成小改动和 60—120 秒复述。
8. 保存证据并小步提交。

AI 可以提高编码速度，但需求、权限、事务、数据、安全、测试结论和回滚责任仍属于工程师。

## 明确非目标

- React 不作为本轮主线；已有 Vue 经验继续转化为就业资产。
- 不制作多个普通 CRUD 项目；一个旗舰项目持续加深。
- 不默认拆微服务，不为关键词硬上 Kafka、Kubernetes 或多 Agent。
- 不把 AI 应用路线包装成算法研究岗训练。
- 不虚构商业年限、客户、生产规模、模型指标或部署事实。
- 不一次安装所有后续工具；进入对应阶段再核对和锁定稳定版本。
