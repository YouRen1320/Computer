# 百科重建实施契约

## 最终目标

构建一套能让零基础读者从计算机基本操作开始学习，并能把 Java、Spring、PostgreSQL、Vue、uni-app、Flutter、Python、机器学习与 AI Agent 用于真实工作的中文编程百科全书。它同时是连续课程、项目手册、故障手册和长期参考书。

P8 的 FactoryCare 交付采用学习项目口径：课程仓负责提供端到端教学路线、施工前设计合同、八阶段验收标准和可执行验收框架；真实 Java/Vue/uni-app/Flutter/Python 集成系统，以及 `evidence/factorycare/**` 下的运行、测试、决策和复述证据，由学习者到达对应阶段后亲手产生。开始学习前这些证据不存在是正确状态，课程建设不得预填空目录、伪造绿灯或提前实现未来周次的完整业务系统。这不是缩小 P8，而是把阶段矩阵与既有的非伪造、答案隔离和学习者所有权边界统一起来。P8 的网站、全量索引和分卷出版物仍是课程工程交付，不转嫁给学习者。

P3 的八项方案选择已经在 [`P3-R0-DECISIONS.md`](./P3-R0-DECISIONS.md) 接受。决策接受、P3 实现完成、章节进入 `review`、章节成为 `verified` 和公开发布是五个不同状态，不能相互替代。2026-07-16 后续决定把 P3—P8 的全面审查集中到 P9，执行细则见 [`CONTENT-FIRST-EXECUTION.md`](./CONTENT-FIRST-EXECUTION.md)；该决定调整实施节奏，不改写 R0 历史事实。

P3-R1 原按可独立验证能力拆为两个原子批次：R1-A 负责 profile、工具策略、四份显式公共工件 manifest、确定性 sidecar plan、路径/私有/状态门和完整树写入；R1-B 负责验证执行与生命周期门。R1-B 的生命周期枚举及 phase/status 合法组合门已经完成。按 2026-07-16 内容优先决定，P3 的验证执行收敛为代码内固定 recipe、临时副本和明确预期退出码的轻量 Runner；严格 verification manifest、出版级证据树、未声明输出封闭和独立复审集中到 P9。R1-A 不生成 HTML/EPUB/PDF、不修改 P2 五文件、不晋升章节状态，也不把网络策略冒充 OS 级断网沙箱。

## 单章完成定义

核心章节必须具备：

1. 要解决的问题与可观察学习目标；
2. 前置知识及零基础补救链接；
3. 直觉模型、精确定义与运行过程；
4. 目标版本下可运行的最小示例；
5. 正例、边界、失败案例及错误日志阅读；
6. 调试、测试、安全、隐私和无障碍中适用的部分；
7. 与用户已知语言或框架的对照；
8. FactoryCare 中的真实落点；
9. 预测、动手、故障、需求变更和关闭 AI 独立练习；
10. 复述题、间隔复习点、速查表；
11. 版本、复核日期与直接支持结论的来源；
12. 元数据通过 schema 与仓库校验器。

纯索引、路线页和附录不强制套用完整教学模板，但必须声明内容类型。

## 批次规则

- 正文可按 5—8 章或约 4—8 万个 Unicode 字符组织生产和提交，但 P3—P8 不因达到该规模强制触发全面评审。
- 基础设施批次按可独立验证的能力切分，不为了凑章节数扩大范围。
- P3—P8 完成本批直接相关的 schema、链接、边界、编译、运行或已有测试后即可继续内容生产；不执行阶段性独立 Agent 全面审查、长审查报告、人工版式/无障碍检查、零基础试读或全仓穷举回归。
- 任何“通过”都要准确限定为静态检查、构建或自动化测试；尚未执行的人工版式、无障碍、试读和全局审查必须明确标为延期或未验证。
- P3-R0 规定的零基础试读和七类审查仍是最终质量要求，但根据 2026-07-16 后续决定集中到 P9；AI 自审、作者代读和自动化测试仍不能替代这些证据。
- 延期审查期间，章节不得仅因正文写完或自动检查通过而晋升 `verified`，也不得进入正式公开发布。

## 内容规模目标

- 主叙事目标：150—190 万 Unicode 字符，不含代码；
- 实验、练习、解析和索引目标：70—100 万 Unicode 字符，不含代码；
- 规模是覆盖度信号，不是验收替代品。重复、注水或无来源堆砌不计为完成。

## 兼容策略

迁移期保留 `weeks/`、`learning-kits/` 和现有顶层文档的可用入口，只添加到权威章节 ID 的映射。P3 R1—R3 保留 P2 的五文件外壳，使用隔离 sidecar 做内部预览；四章进入 `review` 前必须单独迁移 P2 公共输入和摘要语义。P9 默认建议移除重复正文而保留必要的跳转页；是否保留长期兼容入口，以 P9 迁移审计结果为准，不预先承诺永久兼容。

## 当前执行边界

2026-07-16 用户已明确取消本轮的套餐百分比停止线，并要求不再估算 Token、查询周额度或用内部活动换算余额。后续按 P0—P9 的真实完成证据推进，直到用户暂停或实施目标完成。P3—P8 采用内容优先节奏，只保留必要自动检查；全面人工/独立审查与全仓回归集中到 P9，详见 [`CONTENT-FIRST-EXECUTION.md`](./CONTENT-FIRST-EXECUTION.md)。`USAGE-CHECKPOINTS.md` 只保留此前历史读数，不再作为当前实施门，也不得因旧读数自行停止新批次。

- 不复制无明确许可的第三方教材、培训 PDF 或图片；
- 不在课程构建阶段伪造学习、面试、项目上线或生产运行证据；
- 不在未经用户授权时推送远程、发布网站或投递岗位。
