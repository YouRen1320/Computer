# 导数、梯度、链式法则与优化

上一章把一批输入通过矩阵变换成输出。本章研究另一个问题：输入稍微变化时，函数输出怎样变化？一元函数的导数描述局部变化率，多元函数的偏导数分别考察每个输入，梯度把这些偏导数组成向量。链式法则把多层计算的局部变化连接起来，梯度下降沿降低目标函数的方向逐步更新参数。

本章只讲数学与可验证的 NumPy 实现，不教授 PyTorch、自动求导、神经网络或生产训练。每个解析公式都要经过手算点和中心有限差分核对，每个更新方向都要看损失轨迹。有限差分是独立数值检查，不是解析梯度的替代品；一次下降也不证明找到了全局最优。

## 1. 从平均变化率到瞬时变化率

函数 `y=f(x)` 在 x 从 a 变到 b 时，平均变化率是：

```text
[f(b)-f(a)]/(b-a)
```

它是连接图像两点的割线斜率。若设备折旧在一段时间内完全线性，任意区间平均变化率相同；若函数弯曲，不同区间斜率不同。

### 1.1 缩短区间

想知道 x=a 附近的瞬时变化率，可令 b=a+h，让 h 越来越接近 0：

```text
[f(a+h)-f(a)]/h
```

若这个比值趋近稳定值，就把极限定义为导数 `f'(a)`。不能直接令 h=0，因为分母会为零；导数由“趋近过程”定义，不是执行一次除零。

### 1.2 图像直觉

当两个点靠近，割线趋近曲线在 a 点的切线。切线斜率正，函数局部随 x 增大而上升；负则下降；零表示一阶局部平坦，但不自动表示最小值。山顶、谷底和水平拐点都可能导数为零。

### 1.3 局部不等于全局

导数只描述极小邻域。某点斜率为负，不表示函数以后永远下降；斜率会随位置变化。把训练某几步下降外推成永久稳定，是越界推断。

## 2. 常见一元导数规则

### 2.1 常数、幂与线性组合

常数 c 的导数为 0；`x` 的导数为 1；`x^n` 的导数为 `n x^(n-1)`。常数倍可提出，和的导数等于导数之和：

```text
d/dx [a f(x)+b g(x)] = a f'(x)+b g'(x)
```

例如 `f(x)=3x²+2x+5`，`f'(x)=6x+2`。在 x=1，导数 8，表示输入增加很小量 Δx 时，输出一阶近似增加 `8Δx`。

### 2.2 乘积与商

乘积法则 `(fg)'=f'g+fg'`，不是 `f'g'`。商法则 `(f/g)'=(f'g-fg')/g²`，且 g 不为 0。复杂表达式先拆中间变量，能减少漏项。

### 2.3 指数与对数

`e^x` 导数仍为 `e^x`，`ln x` 导数为 `1/x`（x>0）。其他底数需要常数因子。定义域仍有效：公式看起来能写，不表示对非法输入存在实数导数。

### 2.4 不可导点

绝对值 `|x|` 在 0 左斜率 -1、右斜率 1，不存在唯一导数。分段函数的连接点、尖角和跳跃处要检查左右变化率。数值差分可能给一个貌似值，不能因此声称数学上可导。

## 3. 导数的近似意义

在 a 附近：

```text
f(a+Δx) ≈ f(a)+f'(a)Δx
```

这是局部线性近似。Δx 越小、函数越平滑，通常越准确。它解释了为什么导数能用于敏感度分析和小步优化。

### 3.1 误差与尺度

若 Δx 很大，忽略的高阶曲率变重要。导数单位是“输出单位/输入单位”；输入从小时改分钟，数值会改变。比较不同参数的梯度大小前，应考虑尺度。

### 3.2 导数为零的含义

导数为零称驻点候选。`x²` 在 0 是最小，`-x²` 在 0 是最大，`x³` 在 0 既非局部最大也非局部最小。需要看邻域、二阶信息或直接比较函数值。

## 4. 多元函数与偏导数

多元函数 `f(x,y)` 接收多个输入。偏导数 `∂f/∂x` 在求导时暂把 y 当常数；`∂f/∂y` 暂把 x 当常数。它们回答沿各坐标轴小幅移动时的变化率。

例如：

```text
f(x,y)=x²+3xy+y²
∂f/∂x=2x+3y
∂f/∂y=3x+2y
```

交叉项 `3xy` 对 x 求偏导得到 3y，对 y 得 3x。把另一个变量当常数不是把它设为 0。

### 4.1 梯度向量

梯度把所有偏导按参数顺序排列：

```text
∇f(x,y)=[∂f/∂x, ∂f/∂y]
```

若参数向量形状 `(P,)`，梯度必须同形状 `(P,)`，每个位置对应同一参数。参数顺序错，即使数值集合相同也会更新错对象。梯度是形状合同的一部分。

### 4.2 梯度方向

在欧氏空间的局部意义下，梯度指向函数上升最快方向，负梯度指向下降最快方向。沿单位方向 u 的方向导数是 `∇f·u`。由点积可知与梯度同向最大，与负梯度同向最小。

“下降最快”是当前位置、给定坐标尺度和足够小步长下的一阶结论，不保证大步走后仍下降。

## 5. 链式法则

程序常由多层中间变量组成。若 `y=f(u)`、`u=g(x)`，则：

```text
dy/dx = (dy/du)(du/dx)
```

链式法则把外层对中间量的变化率与中间量对输入的变化率相乘。

### 5.1 一元例子

`y=(2x+1)²`。设 `u=2x+1`，`y=u²`：

```text
dy/du=2u
du/dx=2
dy/dx=2u×2=4(2x+1)
```

常见错误是只对平方求导得到 `2(2x+1)`，漏掉内层导数 2。有限差分能暴露这个固定倍数差。

### 5.2 多分支与求和

若一个变量通过多条路径影响输出，每条路径的贡献要相加。例如 `y=x²+x³` 可看作两条分支，导数 `2x+3x²`。计算图中“沿路径相乘、在汇合处相加”是重要直觉。

### 5.3 多元复合

若 `r=2x+y-5`，`L=r²+0.5(x-1)²`，x 同时通过 r 和正则项影响 L：

```text
∂L/∂x = 2r·∂r/∂x + (x-1)
       = 2r·2 + (x-1)
       = 4r + (x-1)

∂L/∂y = 2r·∂r/∂y
       = 2r·1
       = 2r
```

漏掉 `∂r/∂x=2` 或漏掉第二条 x 路径，都会得到错误梯度。

## 6. 本章完整手算 oracle

定义二元损失：

```text
L(x,y)=(2x+y-5)² + 0.5(x-1)²
```

在点 `(1,1)`：

```text
r=2×1+1-5=-2
L=(-2)²+0.5×0²=4
∂L/∂x=4×(-2)+(1-1)=-8
∂L/∂y=2×(-2)=-4
∇L(1,1)=[-8,-4]
```

这四个数是独立 oracle。解析程序必须得到完全相同结果，中心差分应在声明容差内接近。错误实现若 x 分量漏乘内层 2，会得到 `[-4,-4]`；第二分量正确、第一分量错误，能精确定位链式法则失败。

### 6.1 形状合同

```text
point:    (2,)  顺序 [x,y]
gradient: (2,)  顺序 [dL/dx,dL/dy]
loss:     ()    标量
```

如果函数返回 `(1,2)` 或颠倒两个分量，即使数值接近也违反合同。批量点的梯度是另一份合同，不在基础函数中偷偷加入批次轴。

## 7. 有限差分

前向差分：

```text
[f(x+h)-f(x)]/h
```

中心差分：

```text
[f(x+h)-f(x-h)]/(2h)
```

对平滑函数，中心差分通常具有更好的截断误差性质。多元函数对第 i 个分量差分时，只改变该分量，其他保持不变。

### 7.1 逐分量算法

```python
for i in range(point.size):
    step = np.zeros_like(point)
    step[i] = h
    numerical[i] = (loss(point + step) - loss(point - step)) / (2*h)
```

这条路径不调用解析梯度，因此可作为相对独立的实现检查。若测试内部又调用解析梯度生成期望，就失去 oracle 独立性。

### 7.2 h 不能为零或任意小

h 太大时，差分跨越的区间太宽，局部近似失真；h 太小时，两个非常接近的浮点数相减会发生消去，舍入误差被除以小 h 放大。因此误差常先随 h 变小而下降，之后又上升。

对 `sin(x)` 在 0 的导数为 1。中心差分 h=1 时给 `sin(1)≈0.84147`，误差明显；h=`1e-5` 非常接近 1。但没有一个 h 对所有函数、尺度和 dtype 都最佳。

### 7.3 比较规则

使用绝对与相对容差，例如 `np.testing.assert_allclose(analytic,numeric,atol=1e-7,rtol=1e-7)`。先根据函数尺度、h 和浮点类型声明容差，再运行。若失败，先打印分量索引、解析值、数值值、绝对/相对误差，不要立即扩大容差。

### 7.4 有限差分的边界

不可导点没有唯一解析梯度，中心差分可能因对称而给 0；随机函数、含状态变化函数和分段跳跃函数也不适合直接检查。固定所有外部输入，选择平滑点，并避免在边界跨出定义域。

## 8. 梯度下降

最小化损失时，基础更新式：

```text
θ_new = θ_old - η ∇L(θ_old)
```

θ 是参数向量，η 是正学习率。减号来自负梯度是局部下降方向。若误写加号，在本章 oracle 点第一步会明显升高损失。

### 8.1 一步手算

起点 `[1,1]`，梯度 `[-8,-4]`，学习率 0.1：

```text
new = [1,1] - 0.1[-8,-4] = [1.8,1.4]
r=2×1.8+1.4-5=0
L=0²+0.5×0.8²=0.32
```

损失从 4 降到 0.32。若符号反转，得到 `[0.2,0.6]`，残差 -4，正则项 0.32，总损失 16.32，首步就暴露错误。

### 8.2 学习率直觉

η 太小，每步移动少，下降慢；合适时较快降低；太大可能越过谷底、振荡或发散。不能只看最终一步，要保存完整轨迹和参数是否有限。

本章同一起点运行 12 步：

- η=0.01：损失从 4 缓慢降到约 0.53019；
- η=0.1：首步到 0.32，12 步约 0.19596；
- η=0.3：首步升到 18.88，随后迅速发散，12 步约 9.87×10^8。

这些是特定二次函数和起点的可复现玩具结果，不是通用最佳学习率，更不是生产训练指标。

### 8.3 单调下降不是绝对要求，但基础实验可用

复杂优化中损失可能因随机批次等原因波动。本章是确定性、平滑二次函数，合理学习率预期轨迹下降，因此可把它作为 oracle。不能把以后随机训练的每步不单调直接判定为 bug，也不能用“随机会波动”掩盖明显发散。

## 9. 局部最优、全局最优与驻点

局部最小只比附近点小，全局最小不大于定义域所有点。凸函数的任一局部最小也是全局最小；一般非凸函数可能有多个谷底、平台和鞍点。

### 9.1 本章二次函数的结构

`L=(2x+y-5)²+0.5(x-1)²` 是非负项之和。全局最小要两项同时为 0：`x=1` 且 `2x+y-5=0`，所以 `y=3`，最小值 0。解析梯度在 `(1,3)` 也为 `[0,0]`。这里我们可以用代数证明全局最优，而不是因为迭代看似收敛。

### 9.2 鞍点

`f(x,y)=x²-y²` 在原点梯度为零，但沿 x 方向上升、沿 y 方向下降，是鞍点。仅检查梯度范数小不能保证最小。数值优化还会遇到平坦区、边界约束和数值精度停止。

### 9.3 初始点依赖

对非凸目标，不同起点可能到达不同局部最优。固定一个起点用于回归测试可以，但性能结论需要多起点和更完整实验设计。仍不能把最好一次挑出来当稳定结果。

## 10. 梯度检查的完整工作流

1. 写出函数、定义域、参数顺序和形状。
2. 引入中间变量，把计算拆成节点。
3. 纸上逐路径推导每个偏导。
4. 选小而非对称的点，手算损失与梯度。
5. 独立实现中心差分，固定 h 与容差。
6. 逐分量比较，报告最大误差和索引。
7. 做一次负梯度更新，确认小步损失下降。
8. 注入已知错误，证明测试真的会红。
9. 修复后重跑原命令并保存绿灯证据。
10. 记录未覆盖边界，例如不可导点和其他尺度。

这比“程序没有抛异常”强得多。一个永远返回零向量的梯度函数可以正常运行，但在非驻点会被手算和差分立即抓住。

## 11. 四类故障与首个可信证据

### 11.1 链式法则漏项

表现：某些分量与有限差分相差固定倍数，另一些可能正确。失败阶段是解析梯度 oracle 比较；首证据是具体分量 `expected -8, actual -4`。回到计算图，检查从参数到损失的每条路径和局部导数。

### 11.2 梯度符号反转

表现：解析梯度可能与差分一致，但更新写成 `+ηg`，第一步损失上升。失败阶段是优化更新/轨迹；首证据是起点、梯度、新点和首步损失。修复更新符号，不能给梯度整体乘 -1 让另一个测试偶然通过。

### 11.3 有限差分步长失真

表现：解析公式正确，但数值检查误差随 h 异常。失败阶段是数值 oracle 配置；首证据是多个 h 下误差表。排查尺度、浮点 dtype、不可导点和随机性。保留解析手算，避免把数值近似当绝对真理。

### 11.4 学习率发散

表现：损失震荡增大、参数绝对值快速增大，最终可能无穷或 NaN。失败阶段是优化轨迹；首证据是最早开始升高的步数和参数。减小学习率、检查缩放与梯度公式，并设置有限性/增长保护。即使调小后下降，也要保留“只在此目标与尺度验证”的残余风险。

## 12. 常见误区

### 12.1 把导数当差值

导数是变化率，不是 `f(x+1)-f(x)` 的固定差。后者是步长 1 的有限差，可能离局部很远。

### 12.2 求偏导时把其他变量设零

“视为常数”不是“改成零”。`xy` 对 x 的偏导为 y，不是 0。

### 12.3 只检查梯度总范数

总范数接近可能掩盖分量互换或某正某负。应逐分量检查，并保留参数名称/索引。

### 12.4 用同一错误实现生成期望

若数值检查内部调用了解析梯度，二者会一起错。oracle 路径必须尽量独立：纸笔公式、中心差分和轨迹分别提供证据。

### 12.5 看见下降就宣称最优

损失下降只证明所走几步较低，不证明收敛，不证明全局最优，也不证明真实业务价值。需要最优性结构或更完整实验。

## 13. NumPy 实现与版本边界

本章实现只需数组、索引和浮点断言。`numpy.gradient` 官方函数主要根据网格样本值估计梯度，并支持间距/轴等参数；我们的参数梯度检查直接对可调用损失函数逐分量扰动，职责不同。不要因为名称相同就互换。

## 15. 方向导数与梯度的几何核对

只看两个偏导的数字容易失去整体直觉。给定单位方向 `u=[u1,u2]`，从点 θ 沿 u 移动很小距离 t，变化率为方向导数：

```text
D_u L(θ)=∇L(θ)·u
```

它把上一章点积与本章梯度连接起来。因为 `u` 长度限制为 1，点积在 u 与梯度同向时最大，在反向时最小。若 u 与梯度垂直，方向导数为 0，表示一阶近似下沿该方向移动不改变损失；这仍不保证有限步长后完全不变。

在本章点 `(1,1)`，梯度 `g=[-8,-4]`，其长度 `sqrt(80)=4sqrt(5)`。沿正 x 单位方向 `[1,0]` 的变化率为 -8，沿正 y 为 -4；所以很小的正 x 移动比同样大小的正 y 移动下降更快。沿负梯度单位方向 `-g/||g||` 的方向导数是 `-||g||`，是所有单位方向中的最小值。

可以用一维切片验证方向导数。定义 `φ(t)=L(θ+t u)`，则 `φ'(0)=∇L(θ)·u`。对任意非轴方向做中心差分：

```text
[L(θ+h u)-L(θ-h u)]/(2h)
```

它应接近解析点积。这是逐坐标有限差分之外的补充证据，能发现梯度分量顺序颠倒。选择 `u=[3/5,4/5]` 而不是对称方向，可降低错误排列偶然通过的可能。

### 15.1 坐标尺度会改变“最快”

若 x 用小时、y 用分钟，单位数值尺度相差 60 倍，普通欧氏梯度的方向会随单位变换。数学公式没有错，但参数化不同。真实优化常需要标准化、预条件或自适应方法；这些属于后续内容。本章要求至少记录每个参数单位，避免把梯度分量绝对值直接解释成业务重要性。

### 15.2 梯度不是特征贡献解释

梯度说明在当前点微调输入的局部敏感度，不等于某特征造成结果，也不等于全局重要性。相关输入、非线性、边界和数据分布都会影响解释。FactoryCare 中不能用某一时刻梯度绝对值给员工或设备下因果结论。

## 16. 曲率与学习率的最低限度直觉

导数描述斜率怎样，二阶导数描述斜率怎样变化，即曲率。一元二次函数 `f(x)=a(x-c)²` 的梯度为 `2a(x-c)`。a 越大，谷底越陡；同一学习率产生的更新越大，越容易跨过最低点。

多元函数在不同方向可能一边陡、一边平。固定小学习率照顾陡方向时，沿平方向会前进缓慢；调大学习率又可能在陡方向振荡。这解释了为什么“学习率越大越快”不成立，也解释了轨迹需要分量级观察。

本章不要求计算 Hessian 矩阵或特征值，但应知道：学习率稳定范围与目标曲率有关，不存在脱离函数尺度的万能数值。0.3 在本章二次函数发散，不意味着任何项目的 0.3 都发散；0.1 在这里下降，也不证明所有目标都安全。

### 16.1 一维更新的精确观察

对 `f(x)=a(x-c)²`，梯度下降误差 `e=x-c` 的更新是：

```text
e_new = (1-2aη)e_old
```

若绝对值 `|1-2aη|<1`，误差逐步缩小；系数为负时会在谷底两侧振荡但幅度缩小；绝对值大于 1 时幅度增长而发散。这个简单推导展示了学习率、曲率和稳定性的关系。多元情况更复杂，但轨迹证据的思想相同。

### 16.2 停止条件

固定步数便于回归测试，真实优化还可根据梯度范数、损失变化、参数变化、时间预算或验证指标停止。每种条件都有风险：梯度小可能在鞍点，损失变化小可能是学习率太小，训练损失继续下降也可能不再改善未见数据。停止原因应作为证据保存，不能只记录“完成”。

## 17. 纸笔推导与代码审查清单

面对一个新损失函数，先把自然语言变成下列表格：

```text
节点 | 公式 | 输出形状 | 依赖输入
r    | 2x+y-5 | 标量 | x,y
q    | r²     | 标量 | r
p    | 0.5(x-1)² | 标量 | x
L    | q+p    | 标量 | q,p
```

反向审查时，从 L 开始列每条路径。x 到 L 有 `x→r→q→L` 和 `x→p→L` 两条，y 只有第一条。路径上局部导数相乘，同一输入的多路径相加。这样比在一行长公式上凭眼睛求导更容易发现漏项。

代码审查逐项回答：

1. 参数数组的顺序和 shape 是否明示？
2. 损失是否返回真正标量，而不是长度一数组？
3. 中间变量是否与纸上符号一一对应？
4. 每个参数到损失的所有路径是否覆盖？
5. 中心差分是否只修改一个分量并恢复原值？
6. h、dtype、绝对/相对容差是否记录？
7. 测试点是否避开不可导边界且不全为零？
8. 是否先核对梯度，再核对更新符号？
9. 轨迹是否保存初始损失和每一步，而非只有终点？
10. NaN、无穷和爆炸增长是否能使验证失败？

### 17.1 三层 oracle

第一层是精确手算点，能解释每个数；第二层是多个点的有限差分，扩大覆盖；第三层是优化轨迹，验证梯度被正确用于更新。三层失败含义不同：手算失败优先查公式或索引，差分失败查解析实现与数值配置，轨迹失败查符号、学习率和状态更新。

### 17.2 故障注入必须能被抓住

先故意删掉链式因子 2，确认 x 分量测试红；再恢复。故意把减号改加号，确认首步损失测试红；再恢复。故意把 h 改成 1，用正弦检查确认近似误差红；再恢复。故意把学习率改 0.3，确认轨迹增长保护红；再恢复并运行同一命令。一个从未见过红灯的测试可能根本没检查目标风险。

### 17.3 残余风险陈述

即使所有工件通过，仍只验证这个平滑二次函数、几个点、float64 和当前库版本。未覆盖不可导函数、约束优化、随机梯度、大参数数组、混合精度、自动求导和生产数据。把这些明确列为非目标，比模糊说“梯度实现完全正确”更专业。

## 19. 120 秒复述模板

“导数是输入微小变化时输出的局部变化率，可由差商极限理解；多元函数对每个输入求偏导，按参数顺序组成梯度。梯度指向局部最快上升方向，所以梯度下降用 `参数减学习率乘梯度`。复合函数用链式法则，沿路径局部导数相乘，多路径贡献相加。解析梯度要用手算点和中心有限差分逐分量核对，再看小步损失轨迹。越界反例是损失下降几步就宣称找到全局最优或生产模型有效；下降只是一段局部数值证据。本章不教授自动求导框架，也不产出生产决策。”

## 21. 参考答案要点

1. 会除以零；导数是 h 趋近 0 时差商的极限。
2. `6x+2`，代入 1 得 8。
3. 暂视为常数，结果为 y，不是把 y 设为零。
4. 内层 `2x+1` 对 x 的导数 2。
5. 残差 -2，梯度 `[-8,-4]`。
6. 它近似对应的偏导，其他变量必须固定。
7. 太大产生截断/非局部误差；太小产生浮点消去和舍入放大。
