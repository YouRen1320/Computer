> 神经网络不是一段不可解释的魔法。最小前馈网络只是若干“线性变换—非线性变换”的组合；训练只是计算损失对每个参数的导数，再按优化规则更新参数。本章从标量和小矩阵开始，要求你能在纸上追踪每个数、每个形状和每条梯度路径。PyTorch 会在后续章节把这些步骤自动化，本章不依赖其 API。

## 1. 本章边界与学习证据

本章负责建立以下稳定心智模型：

- 神经元、层、参数、激活值分别是什么；
- 前向传播怎样从输入得到预测；
- 损失函数怎样把预测误差压缩成训练目标；
- 反向传播怎样使用链式法则得到参数梯度；
- 优化器怎样使用梯度提出下一组参数；
- 为什么梯度会消失、爆炸或因实现错误而失真；
- 怎样用有限差分和形状账本建立独立证据。

本章不负责证明某个真实业务模型有效，不选择生产网络规模，不教授 GPU、分布式训练或 PyTorch API，也不把一次小样本下降当作泛化能力。FactoryCare 中，Java 继续拥有工单、设备、权限和状态机；Python 模型只能给出可重建的分数、建议或排序，Java 决定是否采用并记录最终事实。

真正的完成证据不是“代码能运行”，而是：手算值、独立 NumPy 实现和有限差分在明确容差内一致；每个中间量的形状有账本；注入错误后测试能红，再修复并重跑变绿。

## 2. 从线性单元开始

一个最小线性单元接收输入向量 `x`、权重向量 `w` 和偏置 `b`：

\[
z = x \cdot w + b = \sum_{j=1}^{d} x_jw_j+b
\]

其中 `d` 是输入特征数。权重决定每个输入对结果的方向和幅度，偏置允许决策边界不必经过原点。`z` 常被称为预激活值，因为它还没有经过非线性函数。

若只有线性层，无论堆多少层，整体仍可化成一个线性变换。例如 `xW1W2` 等于 `x(W1W2)`。因此，深度本身不会产生复杂边界；非线性激活才使多层组合能够表示弯曲、分段或更复杂的函数。

不要把“神经元”理解成生物神经元的精确模拟。这里它是一个参数化计算单元。类比可以帮助入门，但数学合同以输入、参数、输出和导数为准。

## 3. 从一个样本推广到一批样本

工程实现通常把一批样本组成矩阵：

- `X`：`(B, D_in)`，`B` 个样本，每个 `D_in` 个特征；
- `W`：`(D_in, D_out)`；
- `b`：`(D_out,)`；
- `Z = X @ W + b`：`(B, D_out)`。

偏置依靠广播加到每一行。广播方便，但也是形状错误高发区。若误把 `b` 写成 `(B, 1)`，某些尺寸下运算仍能执行，却表达了完全不同的参数语义。每一层都应记录“名称、含义、形状、是否参数、是否按批次归约”。

一个两层前馈网络可以写成：

\[
Z_1=XW_1+b_1,\quad H=\phi(Z_1),\quad \hat{Y}=HW_2+b_2
\]

`W1,b1,W2,b2` 是可学习参数，`Z1,H,Y_hat` 是本次前向的中间值。训练时需要保留足以计算局部导数的信息；推理时通常不需要构建梯度图。

## 4. 激活函数不是装饰

### 4.1 ReLU

\[
\operatorname{ReLU}(z)=\max(0,z)
\]

当 `z>0` 时导数为 `1`，当 `z<0` 时导数为 `0`。在 `z=0` 处经典导数不存在，软件通常选择一个约定值。ReLU 计算简单、正区间不饱和，但某个单元若长期落在负区间，其梯度可能总为零，形成“死亡 ReLU”。

### 4.2 Sigmoid

\[
\sigma(z)=\frac{1}{1+e^{-z}},\qquad \sigma'(z)=\sigma(z)(1-\sigma(z))
\]

输出在 `(0,1)`，适合表达二分类概率参数，但大正数或大负数处导数接近零。把 Sigmoid 层堆得很深会加重梯度消失。数值实现还要避免直接计算巨大指数导致溢出。

### 4.3 tanh

\[
\tanh'(z)=1-\tanh^2(z)
\]

输出在 `(-1,1)` 且以零为中心，但两端同样饱和。选择激活函数要结合层职责和优化行为，不能只凭“流行”。

输出层是否使用激活取决于任务合同：回归常用线性输出；二分类常用一个 logit 配合二元交叉熵；互斥多分类常用多个 logits 配合交叉熵。训练时的“logit”是尚未归一化的分数，不等于概率。

## 5. 前向传播的可审计例子

取一个样本：

```text
x = [1, 2]                         shape (2,)
W1 = [[ 0.5, -1.0],
      [ 1.0,  0.5]]               shape (2, 2)
b1 = [0.0, 0.5]                   shape (2,)
W2 = [[ 0.4],
      [-0.2]]                     shape (2, 1)
b2 = [0.1]                        shape (1,)
y = [0.4]                         shape (1,)
```

先算隐藏层：

```text
z1 = x @ W1 + b1
   = [1*0.5 + 2*1.0 + 0.0,
      1*(-1.0) + 2*0.5 + 0.5]
   = [2.5, 0.5]
h  = ReLU(z1) = [2.5, 0.5]
```

再算输出：

```text
y_hat = h @ W2 + b2
      = 2.5*0.4 + 0.5*(-0.2) + 0.1
      = 1.0
```

若采用单样本半平方误差：

\[
L=\frac{1}{2}(\hat y-y)^2=\frac{1}{2}(1.0-0.4)^2=0.18
\]

这里的 `1/2` 不是必须，它只是让求导时的 `2` 抵消。必须把定义写进合同；若手算用半平方误差，代码却用均方误差或批次总和，梯度会相差固定比例。

## 6. 损失函数回答“怎样算错”

损失函数不是业务价值本身，而是训练可优化的代理目标。

### 6.1 平方误差

回归常见：

\[
\operatorname{MSE}=\frac{1}{N}\sum_i(\hat y_i-y_i)^2
\]

它对大误差惩罚更强，也更易受离群值影响。`mean` 与 `sum` 会改变梯度尺度；批量大小变化时，使用 `sum` 还会改变有效步长。

### 6.2 二元交叉熵

对二分类概率 `p`：

\[
L=-[y\log p+(1-y)\log(1-p)]
\]

工程上通常把 logit 与稳定的交叉熵实现组合，避免先算极接近 `0/1` 的概率再取对数。不要在已经带 Sigmoid 的输出上再次使用“with logits”版本，否则会重复变换。

### 6.3 多分类交叉熵

Softmax 把 logits 转为总和为一的分布，多分类交叉熵惩罚真实类别的低概率。稳定实现会用“减最大值”和 log-sum-exp 技巧。本章只要求理解合同；Softmax 与注意力在下一章详细展开。

类别不均衡时，单纯降低平均损失可能牺牲少数类。类别权重、采样、阈值和指标需要验证集证据。任何损失下降都不自动证明公平、可解释或业务收益。

## 7. 反向传播就是组织好的链式法则

假设计算图为 `x -> z1 -> h -> y_hat -> L`。反向传播从标量损失开始，沿图的反方向，把“上游梯度”乘以当前节点的局部导数。

若 `u=f(v)` 且损失为 `L(u)`：

\[
\frac{\partial L}{\partial v}=\frac{\partial L}{\partial u}\frac{\partial u}{\partial v}
\]

有多个下游分支时，同一变量收到的梯度要相加，因为损失通过多条路径依赖它。反向传播不是数值优化器；它只高效求梯度。SGD、Adam 等优化器随后决定如何使用梯度。

## 8. 手算两层网络的全部梯度

继续前面的例子。半平方误差对输出的导数：

```text
dL/dy_hat = y_hat - y = 1.0 - 0.4 = 0.6
```

输出层 `y_hat = h @ W2 + b2`：

```text
dW2 = outer(h, 0.6) = [[1.5], [0.3]]
db2 = [0.6]
dh  = 0.6 * W2 = [0.24, -0.12]
```

两个 `z1` 都大于零，因此 ReLU 局部导数为 `[1,1]`：

```text
dz1 = dh * ReLU'(z1) = [0.24, -0.12]
dW1 = outer(x, dz1)
    = [[ 0.24, -0.12],
       [ 0.48, -0.24]]
db1 = [0.24, -0.12]
dx  = dz1 @ W1.T = [0.24, 0.18]
```

`dx` 在本次参数训练中通常不更新输入，但它是检查链式法则和上游层梯度的证据。若网络前面还有层，`dx` 就会继续向前传播。

梯度形状必须与对应变量相同：`dW1.shape == W1.shape`、`db1.shape == b1.shape`。形状相同仍不代表值正确，但形状不同一定说明合同错误。

## 9. 一次梯度下降更新

最基本的随机梯度下降：

\[
\theta_{new}=\theta_{old}-\eta\nabla_\theta L
\]

学习率 `eta` 为 `0.1` 时：

```text
W2' = [[0.4], [-0.2]] - 0.1 * [[1.5], [0.3]]
    = [[0.25], [-0.23]]
b2' = [0.1] - 0.1 * [0.6] = [0.04]

W1' = [[ 0.476, -0.988],
       [ 0.952,  0.524]]
b1' = [-0.024, 0.512]
```

更新后应用同一输入重新前向，损失应下降，但“一步下降”只是局部验算，不是优化算法对所有问题的保证。若把减号写成加号，通常沿梯度上升；若学习率过大，即使符号正确也可能跨过低点并发散。

参数更新必须发生在全部梯度计算完成之后。若计算 `dW1` 之前就原地修改 `W2`，反向链使用的参数不再属于本次前向，得到混合版本的错误梯度。

## 10. 批次、归约与梯度尺度

批次大小 `B` 时，输出层常见矩阵梯度：

```text
dW2 = H.T @ dY
db2 = dY.sum(axis=0)
dH  = dY @ W2.T
```

如果损失定义为批次平均，还要让 `dY` 包含 `1/B`；如果定义为总和则不除。最危险的错误是前向报告平均损失，反向却按总和求导。损失数值看似合理，有限差分会稳定揭露固定倍数差异。

维度为 `1` 时，`squeeze` 可能悄悄删除批次轴，代码在单样本通过、在多样本失败。建议训练核心保持二维批次合同，即使 `B=1` 也使用 `(1,D)`。

## 11. 参数梯度与激活梯度要区分

- 参数梯度：`dW/db`，优化器用它更新模型；
- 激活梯度：`dH/dZ/dX`，用于把影响传给更早的层；
- 损失对预测的梯度：连接目标函数与网络；
- 梯度缓存：实现层面的存储，不是新的数学对象。

“梯度是误差”不够准确。误差是预测与目标的差异，梯度是损失对某变量的局部变化率。某个样本误差大，不保证某个参数梯度也大；还要经过特征值、激活导数和所有路径。

## 12. 有限差分：独立检查解析梯度

对某个标量参数 `theta`，中心有限差分：

\[
g_{num}=\frac{L(\theta+\epsilon)-L(\theta-\epsilon)}{2\epsilon}
\]

它只需前向函数，不复用反向公式，因此能作为相对独立的 oracle。逐参数流程：

1. 保存原参数；
2. 只把该元素加 `epsilon`，计算 `L+`；
3. 只把该元素减 `epsilon`，计算 `L-`；
4. 恢复原参数；
5. 比较数值梯度与解析梯度。

常用相对误差：

\[
\frac{|g_{ana}-g_{num}|}{\max(1,|g_{ana}|,|g_{num}|)}
\]

`epsilon` 太大有截断误差，太小有浮点消去误差。float64 小网络可从 `1e-6` 尝试，并明确 `rtol/atol`。ReLU 在零点不可导；梯度检查样例应避开零点，或明确软件的次梯度约定。

有限差分复杂度与参数数量成正比，适合小网络抽查，不适合每步检查大型模型。它能证明当前输入附近的实现一致，不能证明模型结构正确、数据无泄漏或业务目标合理。

## 12.1 计算图、局部雅可比与向量—雅可比乘积

初学时常问：“中间变量是向量，怎么还能像标量一样乘导数？”严格地说，向量函数的导数是雅可比矩阵。例如 `z=xW+b` 的输出每一维都可能依赖输入多维。若显式构造每层完整雅可比，内存和计算会非常大。

反向模式自动微分的关键是：最终损失通常是标量，我们不需要孤立保存每个完整雅可比，只需把下游梯度向量与当前局部雅可比相乘，得到对上游变量的向量—雅可比乘积。矩阵公式 `dW=X.T@dZ`、`dX=dZ@W.T` 正是这类乘积的高效形式。

这解释了三个事实：

- 反向传播不是“把前向公式倒着运行”，而是按图反向组合局部导数；
- 一个变量被多条路径使用时，来自各路径的梯度必须相加；
- 中间值若被错误原地覆盖，局部导数所需上下文可能丢失。

对标量损失调用反向最自然；若输出不是标量，需要先指定怎样把多个输出组合，或提供外部上游梯度。后续 PyTorch 中的这些 API 行为都建立在此数学事实上。

## 12.2 梯度累积与微批次归约

显存不足时可以把一个逻辑批次拆成多个微批次，分别反向后累积梯度，再更新一次。但要保持与完整批次同一损失定义：若每个微批次都先取均值再直接相加，不同大小微批次会被等权，而不是每个样本等权。

一种可审计做法是累计每个微批次的损失总和梯度，最后除以逻辑批次总样本数；或者按各微批次样本占比缩放其均值梯度。每次逻辑更新前清零一次，更新后再清零。忘记清零会把前一个逻辑批次也累加进来；过早清零则丢掉已累积梯度。

梯度累积只能模拟某些批次梯度语义。含批次统计、随机 dropout、数据增强或优化器按步更新状态时，它未必与一次完整大批次完全等价。因此应把“等价范围”写明并用小数据比较，而不是仅因最终 shape 相同就下结论。

## 12.3 数值异常的防线顺序

出现 `nan/inf` 时不要立刻换优化器。更可靠的排查顺序是：

1. 断言原始输入、标签和参数均为有限值；
2. 在每层前向后检查首个非有限激活；
3. 检查损失公式是否对零取对数、除零或指数溢出；
4. 从输出层向前检查首个非有限梯度；
5. 比较梯度范数、参数范数和实际更新量；
6. 再评估学习率、初始化、裁剪和 dtype。

首个非有限位置比最终 `loss=nan` 更可信。简单把 `nan` 替换成零会污染训练证据；正确策略通常是修复公式/输入，或明确拒绝该批次并告警。

## 13. 优化器的稳定原理

### 13.1 SGD

SGD 用当前小批次梯度更新。小批次带噪声，可能帮助跳出某些狭窄区域，也会造成曲线抖动。学习率通常是首要超参数。

### 13.2 Momentum

动量维护梯度的指数累积，可在方向稳定时加速，在来回振荡方向上缓冲。不同资料对“速度”的符号和更新顺序可能不同，比较公式时必须展开一步，而不能只看名字。

### 13.3 RMSProp 与 Adam

RMSProp 根据梯度平方的移动平均缩放各参数步长。Adam 同时维护一阶矩与二阶矩，并在初期做偏差修正。它们提高了许多任务的易用性，但不会自动给出最佳泛化，也不能补救错误损失、数据泄漏或标签偏差。

### 13.4 权重衰减与梯度裁剪

权重衰减限制参数规模；它与把 L2 项直接加到损失在某些优化器中不完全等价。梯度裁剪在范数超过阈值时缩放或截断梯度，可抑制爆炸，但若长期触发，可能掩盖不合理的学习率、初始化或网络结构。

本章只要求解释这些更新状态的职责。具体 PyTorch 优化器构造参数和版本行为属于后续 API 面。

## 14. 梯度消失与爆炸从哪里来

深层网络梯度包含许多局部导数和权重矩阵的连乘。若典型倍率小于 `1`，信号随层数指数缩小；若大于 `1`，则可能指数放大。

可观察证据包括：

- 早期层梯度范数长期接近零；
- 梯度范数突然极大或出现 `inf/nan`；
- 损失不动、剧烈震荡或数值崩溃；
- 激活大量饱和或全为零；
- 参数更新量相对参数规模过小或过大。

常见缓解手段：合理初始化、非饱和激活、残差连接、归一化、合适学习率、梯度裁剪和更短有效路径。Xavier 初始化常结合近似对称激活，He 初始化常结合 ReLU；核心思想是控制层间激活与梯度方差，而不是死记常数。

只看总损失无法定位问题。应按层记录激活均值/方差、零值比例、梯度范数、参数范数和更新比率，同时避免把高基数字段写进生产指标标签。

## 15. 初始化、随机性与复现

所有权重都初始化为零会让同层神经元保持对称，学到相同特征。随机初始化用于打破对称，但分布尺度必须结合输入维度和激活函数。

复现至少记录：随机种子、数据版本、样本顺序、初始化、数学定义、dtype、依赖版本和运行平台。即使种子相同，不同硬件、并行内核或库版本仍可能产生浮点差异。小手算资产使用 float64、固定常量、CPU NumPy，建立确定性局部真值；它没有证明 GPU 内核确定性。

## 16. 训练、验证与推理不可混为一谈

训练阶段需要标签、损失、梯度和参数更新；验证阶段使用冻结参数评估调参选择；测试集只用于最后独立估计；推理阶段只执行冻结的预处理与前向。

若把测试集反复用于选择网络宽度、学习率或停止轮次，测试信息已进入模型选择，形成泄漏。若线上预处理与训练不同，网络数学正确也会输出错误。神经网络并不取消此前的数据划分、Pipeline 和基线要求。

先建立简单基线很重要：若规则或线性模型已满足目标，复杂网络带来的延迟、维护和解释成本可能不值得。参数更多不等于信息更多。

## 17. 诊断的第一可信证据

### 17.1 激活导数漏乘

表现：输出层梯度正确，隐藏层及更早参数梯度错误。第一证据是某个隐藏参数的有限差分不一致，而 `dW2` 一致。检查 `dZ = dH * phi'(Z)`，不要直接把 `dH` 当 `dZ`。

### 17.2 批次维度混淆

表现：`B=1` 通过，`B>1` 错误或样本间串扰。第一证据是形状账本与中间张量，尤其 `X/H/dY` 的批次轴及偏置归约轴。

### 17.3 损失归约不一致

表现：所有参数梯度方向一致，但相差约 `B` 倍。第一证据是损失定义和数值梯度比例。统一 `mean/sum` 后重跑原有限差分。

### 17.4 梯度符号反转

表现：解析梯度可能数值正确，但更新后损失上升。第一证据是更新公式及一步前后损失。注意“某一步上升”也可能来自大步长，所以先用很小学习率验证方向。

### 17.5 原地更新污染反向

表现：单独公式看似正确，组合后梯度不稳定。检查参数版本：本次反向必须使用本次前向的参数。先完成反向，再统一更新。

诊断记录应保存失败命令、首个失败参数、解析值、数值值、形状、修复 diff 和原命令重跑结果。只贴最终绿色截图不能证明曾定位根因。

## 18. FactoryCare 使用边界

假设模型根据设备信号建议工单优先级：

```text
设备/工单事实、权限、状态机 -> Java
Java 形成最小版本化特征请求 -> Python 推理
Python 返回 priority_hint、score、model_version
Java 校验、展示或交给人工确认 -> Java 写最终 priority
```

Python 不应直接把工单改成紧急，也不应拥有终端用户账户或核心数据库写权限。模型输出必须命名为建议而非事实；低置信、缺特征、分布外输入和服务失败要有明确回退。人工改判是业务事实和反馈候选，但不能未经治理直接变成新标签。

本章的小网络只证明公式与程序一致，不证明其适合 FactoryCare 数据。训练真实模型还需要问题定义、时间切分、泄漏审查、基线、指标、风险和监控。

## 19. 实验操作顺序

1. 抄写输入、参数、目标和形状账本；
2. 不运行代码，手算 `z1,h,y_hat,loss`；
3. 手算 `dW2,db2,dh,dz1,dW1,db1`；
4. 用 NumPy 独立实现前向与反向；
5. 对每个参数元素运行中心有限差分；
6. 断言所有相对误差在容差内；
7. 执行一次 SGD 更新并验证小步长下损失下降；
8. 注入漏乘 ReLU 导数或错误归约，保存红灯；
9. 修复后运行同一命令，保存绿灯；
10. 口述哪些结论没有被这个实验证明。

公开练习故意在隐藏层反向中漏掉 ReLU 导数。私有参考解给出修复，但学习时应先读失败证据和手算，而不是复制答案。
