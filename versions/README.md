# 版本登记册

[`registry.yml`](registry.yml) 是百科全书所有“会随时间变化的表面”的唯一登记处。章节 front matter 和课程目录用稳定 ID（例如 `jdk-25`、`vue-3`）引用它，正文再说明具体行为和兼容范围。

它不是项目锁文件：

- 登记册固定教材采用的主版本、稳定通道和复核策略；
- 进入章节实验时解析并记录当时的 patch 版本；
- 真实项目仍用 `pom.xml`、锁文件、SDK 约束或镜像 digest 固定可复现版本；
- `provisional` 表示主线已选择，但必须在写章/跑例子时重新核验；
- `conceptual` 表示该条目没有一个可统一锁定的版本，章节必须指明实际实现。

修改主版本属于教材契约变更：先核对官方兼容矩阵和迁移说明，再更新登记册、受影响章节证据和发布产物。只改 patch 也必须重新运行相关示例与测试。
